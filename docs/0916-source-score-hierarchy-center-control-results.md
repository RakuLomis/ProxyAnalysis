# 0916源决策对应层级与内容中心H：实验报告

日期：2026-09-21。状态：L0–L11完成。未开启新λ、网络、flow、R4读出或物理约束支线。

## 1. 核心结论

内容×部署中心目标H在留出内容上取得macro-F1=0.864561、CE=0.623125 bits。相对精确配对F（0.853494）和循环错配G（0.865603），合并F1差异的95%描述性区间均跨0；H相对G的CE/Brier有改善区间。

这提供了一个直接的组级对应控制：**在本轮固定源分类器、逐维仿射映射和业务任务下，去掉组内逐访问匹配、仅以同内容同部署pre中心训练，仍能获得接近既有F/G的观察性能。** 但未预设等效界值，不能宣称H与F/G正式等效、精确配对一般无用，或所有任务都只需粗对应。

训练诊断显示四次访问的源预测类别在每个组内全部一致，但源分数仍有非零、部分较大的波动。这与“循环错配改变源分数却不改变训练区源类别”的解释一致。重要限制是：源模型对自己的训练区960个成员出现次数全部分类正确，该一致性是训练内结果，不能代替未见内容证据。

## 2. 数据、范围和方法

仅0916六业务240访问、30内容、SS/VLESS，重复1/2/4/5。五折内容划分：每折192训练、48测试；24训练内容×2部署=48组，每组4次访问。测试6内容整体留出。同内容的部署、重复、父访问、连接及pre/post不在同一折跨集合拆分。

只用Full157维，源有效149维、298个逐维仿射参数。源/出口分类器、T+、U−、T−预处理、alpha=1、λ=1、类别顺序与旧F/G全部冻结。H新增五次二次求解，没有新分类头、网络、超参数搜索或子集筛选。Pytorch312、CPU、float64、单线程。

训练pre先按内容×部署独立分组，在旧目标坐标中计算t_bar；组内每条post输入保持独立，不将192输入压成48个平均post。恢复项与决策项同时改为组中心：

```text
q_i = a⊙v_i+b
z_hat_i = c⊙q_i+d
t_bar_g = mean(t_i | i∈g)
z_bar_g = c⊙t_bar_g+d

L_rec,H = [Σij(q_ij−t_bar_g(i),j)² + Σj a_j²] / (192·149)
L_dec,H = Σi ||P6W(z_hat_i−z_bar_g(i))||² / (192·5)
L_H = L_rec,H + L_dec,H
```

惩罚仍作用于旧U−坐标的斜率，截距不惩罚；8个源无效坐标置零。只改变训练目标，不改变映射容量。Hessian与F/G同折目标的Hessian完全相同，仅右端项改变。

H等价于每个post对组内全部4个pre目标（含同次目标）平均平方损失，差一个与参数无关的常数。它不等价于固定无自配循环G，也不等价于平均所有无自配目标；后者每输入的目标均值为(4t_bar−t_i)/3。

组内pre顺序任意置换后H目标不变，数值测试通过。H仍需要组身份和组成员，不是完全无配对。源W经过业务标签训练，因此也是任务感知方法。

测试仅输入post，用全局仿射映射后送固定源分类器；不输入内容、部署ID或中心，不查找测试内容中心。ID仅为输出键。测试pre仅在预测封存后的离线评价读取。

## 9. 论文表述与停止点

建议当前表述：

> 在训练内源决策空间中，同内容重复保留明显分数波动，但源分类类别一致。保持源分类器和映射容量固定，以内容×部署中心代替逐访问目标仍可实现有效的留出业务迁移；其合并F1未显示相对真配/循环错配的明确差异，且对应关系收益具有部署和评价指标依赖。
