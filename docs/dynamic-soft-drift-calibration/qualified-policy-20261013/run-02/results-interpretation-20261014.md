## 二 任务与方法口径

数据来自extend四个共同有效排他TCP部署：SS、VLESS、Trojan、VMess。六类标签为Bing搜索结果浏览、MDN文档浏览、GitHub仓库浏览、Wikipedia文章浏览、YouTube搜索结果浏览、YouTube视频播放。共30内容，每部署每内容四重复，480访问。

五个全局内容折保持同内容的全部部署、重复、两侧和内部flow整体划分。三遮蔽组固定为G0的GitHub与YouTube搜索、G1的Bing与Wikipedia、G2的MDN与YouTube视频。每个角色使用其他三部署的训练内容和当前目标部署四个覆盖业务的C校准资源；实际目标U训练pre与post均不参与拟合。该设置允许目标C校准，不是目标部署完全不可用的零校准泛化。

保持96维十个归一化直方图块、原P/G基础映射、各角色t与eta、small比例0.1、原W正则及无bias正则、rho=0.01、nu=1、q范围[0,2]不变。模型数值输入不含IP、端口、SNI、协议ID、URL文字或访问身份。模型训练、Hessian、隐式反馈与推理沿用CUDA float64；IO、统计和结果解读在CPU完成。

| 方法 | 学习或回退含义 |
| --- | --- |
| QP | 真配基础映射；源内任务反馈、收缩与关系软惩罚；无原资格时回退P-small |
| QT | 同一P基础映射；任务反馈与收缩，不读取完整关系目标；无原资格时回退P-small |
| QG | 组级基础映射与组级关系目标；无原资格时回退G-small |
| P-small | 固定真配映射的原small方案，无本轮动态q学习 |

QP、QT和QG均只使用实际终态，不选择历史最佳q。stationary门仍为f/v原投影残差均不超过1e-3；finite_progress要求正常20次接受更新、双档下降、规定总目标改善和两档残差均降低至少80%。完整性或后端数值失败不属于普通回退。

## 八 结项判断与论文表述

本轮将此前“很多轨迹未有效优化”的问题推进为“全部轨迹能受控下降，部分达到原有限进展资格，完整资格策略没有超过固定P-small”。这是程序质量与科研判断的实质补全。

可以保留三层结论：

1. 完整QP策略相对S有正式业务收益，不能说它只有恢复或数值用途。
2. 动态q学习相对原P-small、关系惩罚相对QT、精确身份管线相对QG的独立业务增量未建立。
3. 当前没有驻点轨迹，因此不能据此断言外层目标的充分最优解必然无效；但这个未验证可能性也不构成默认追加步数或搜索权重的依据。

合适的论文表述为：在固定四部署、六业务与部分目标校准设置中，资格启用与精确回退使动态幅度方法形成了完整、可审计的预测策略，并保留相对强post参照的收益；然而它没有显示超越固定小比例配对映射的额外用途，当前任务感知幅度优化及关系软惩罚的独立贡献尚未得到支持。

按冻结规则，当前候选结项，保留P-small及完整对照。不要把QP相对S的收益包装为新增动态机制成功，不挑启用者或VLESS子集改写主结论，也不默认放宽80%门、提高40 trial上限或调整rho/nu。若之后转向P-small的观测条件与异批次复核，应作为独立方案确认，不由本轮自动启动。

区间条件于固定模型；队列与历史H结果已经被反复分析，不是全新盲测或外部验证。旧中断阶段全过程读取日志的缺口继续保留。Hy2、AnyTLS、完整物理连接的单侧重建、无索引在线识别和独立异批次泛化不属于本轮已验证范围。
