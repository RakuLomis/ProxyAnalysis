# post输入关联表征残差分支模型说明

## 观测与任务

输入为冻结共同范围的96维post访问直方图，输出六业务概率。需要离线已登记访问边界和合格连接范围；本轮不是无索引在线分段或PCAP生成。

## 计算结构

原P-small为96→6逻辑回归，582参数全部冻结。G为96→16 ReLU→8；残差头接收96维post与八维G输出，104→6，再去除共同logit偏置。残差乘0.1加到原logits。新增2318个参数，不输入协议身份或地址元数据。

训练用pre教师96→16 ReLU→8→6，共1742参数，八维瓶颈为监督目标。教师不进入部署包。分类训练始终使用预测G(post)，不以真实pre瓶颈替代。

## 初始化与训练

仅残差头最后层为零，隐藏层正常随机初始化。因此起点精确复用P-small，训练后没有不退化保证。教师与分支固定1000次全批Adam更新，不宣称神经训练已达到驻点。

教师及分支训练为CUDA float32，原主路和最终logit融合为CUDA float64。非有限值、身份冲突及输入越权终止程序，不按业务表现修门。

## 单侧部署

[deploy.py](F:/Program/VSCode/MyGit/ProxyAnalysis/eval/post_input_associated_representation/deploy.py)只依赖torch，接口为post数值、冻结基座参数和可选残差参数，不读取教师、标签、内容ID、协议ID、配对表或pre。即使生成了八维入口估计，也不是新增真实观测或解密结果。

## 对照含义

A1控制新增容量；A2控制新增表征监督的组级关系；A3检验同次表征目标。三臂都共享已经使用精确配对的P-small，不能把A2解释成全管线无精确关联。
