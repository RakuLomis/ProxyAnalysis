# Extend 代理前后流级概率漂移与信息关系实验报告

日期：2026年10月4日。

本轮已完成四协议排他TCP连接的联合概率、条件核、内容外概率预测、原单位预测、信息统计及共同支持核距离。主范围为23566对连接、480父访问、30内容；既有600访问队列及旧实验保持不变。真实对应模型的八项预登记组合评分比较均通过家族校正正向区间判断。这是当前观测队列和有限离散模型的测量结果，不是新增业务分类收益、精确协议开销或完整信道信息量。

同时保留负载条件扩展的负向结果、原单位长尾误差、窗口分箱退化及有限样本信息估计边界。本轮没有扫描PCAP，没有拟合分类器，没有进入Hy2新数值提取，也没有改变SSL或J系列结果。

## 2 特征模型和训练权限

三族十变量：字节W_up/down、U_up/down；事件P_up/down、E_up/down；交互FR_packet_runs、R_unique_zero_runs。W含重复传输，U为已观测唯一TCP字节；P为正载荷包，E为新字节事件；原FR按正载荷包方向run计算，唯一run按新字节到达计算，二者分开命名。对象是排他双向连接对，不把单向flow或访问汇总误作单连接。

字节固定9箱：0、1–255、256–1023、1024–4095、4096–16383、16384–65535、65536–262143、262144–1048575、1048576以上。计数固定10箱：0、1、2、3、4–7、8–15、16–31、32–63、64–127、128以上。零独立，末箱开放，全部部署/折/两侧共用物理边界。

主频数使用每内容质量1、内容内访问等权、访问内连接等权；连接等权另作敏感性。M0为训练出口边际；M1为真实联合条件核；M2以同内容同部署两侧边际乘积构造匿名组联合表。M1/M2两侧边际保持一致；M2输入删除pair/session/carrier身份并独立打乱两侧行，不强行建立跨重复donor。

每折训练24内容、测试6内容，同内容的协议、重复、两侧及全部连接整体划分。训练、pre-only查询、post评分是不同物理文件包和独立进程，不是OS权限沙箱。预处理资格由双侧离线证据形成；历史数据已经反复分析，不能声称外部盲测。模型数值输入不包含业务标签、内容ID、地址、端口、SNI或endpoint；内容ID仅用于分组控制和统计，标签仅用于bootstrap分层。

预测平滑固定alpha=beta=1内容质量单位。q0=(出口频数+1/k)/(训练质量+1)，K=(联合频数+q0)/(入口行质量+1)。空入口行回退q0。经验信息量来自经验联合分布；平滑信息量从Q(A,B)=训练P(A)K(B|A)重新计算全部边际，不混用两种分布。

拟合及预测全部使用NVIDIA GeForce RTX 4060 Ti、CUDA float64；不是CPU回退。共3250个登记臂估计任务，保存1150个模型文件：主600，连接等权600，合并箱600，闭合子集600，负载条件400，访问窗口450。原单位伴随分布另保存在主/窗口模型文件；描述信息表不作为额外OOF模型。

## 13 本轮结论和停止位置

可以凝练为：在四个已见Extend部署的排他TCP连接队列中，真实pre/post对应形成可在未见内容上使用的低维条件概率关系；在同一两侧数据、成员与权重下，它优于边际及匿名同内容关系。不同部署的字节和交互核有差异，SS较高的run保持与普通TLS/WS+TLS的系统性run增加同时存在。

不能推出：纯协议因果核、精确K或语义阶段；完整流/业务信息保留量；业务分类改善；逐包/逐记录对应；合法会话生成；外部DIRECT、未见配置/日期/协议泛化；AnyTLS逻辑stream或Hy2已取得同等资格。

Q00至Q24的缓存范围工作结项，不追加分类器、分箱/阈值搜索或隐状态拟合。若下一步要扩大AnyTLS粒度、提取Hy2数值、加入可靠角色控制或将核用于生成/分类，需要独立方案和确认，而不是把本轮正向测量自动转换为业务收益。
