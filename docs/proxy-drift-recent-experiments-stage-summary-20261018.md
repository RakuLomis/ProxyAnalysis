# 代理关联与漂移建模：近期实验阶段性总结

截至日期：2026-10-18。项目：ProxyAnalysis。

本文汇总最近一段连续研究：**逆向矩约束模型DP-GAN1-M / Full NER1 → 决策空间前向精炼先导DA-FGAN1 → 角色非对称分配RA1及NR1/NR2数值修订 → P-U50退化诊断 → AD1最小2×2对照。**

此前的固定G读出、温度校准、OR1、SD1、ST1、JAT1已经整理于[10月16日阶段总结](F:/Program/VSCode/MyGit/ProxyAnalysis/docs/associated-representation-experiments-stage-summary-20261016.md)。本文仅以JAT1作衔接，不重复全部更早历史。

这是新增的证据汇总，不修改原报告、模型、预测、门限、bootstrap或停止记录，不启动新训练。主要数字已对照相应机器结果表与终态；“数值执行完成”“源内先导有无资格”“完整H上是否有业务增量”分别陈述。

## 1. 一页结论

### 1.1 这几轮真正回答了什么

1. **让逆向关联模块保留在推理中，并未自动带来整体收益。** Full NER1的主候选F-P-FUSE在完整H上的F1_U为77.9655%，低于P-small的79.6931%，主比较校正区间为负。但它相对同族匿名组控制有正向增量，二者可以同时成立。
2. **只聚焦旧分类器决策空间，也没有在源内建立足够的新增用途。** DA-P在合法源内query上比B0高0.6831pp，但不优于DA-G，CE更差，未通过预定推进屏；没有启动该方法的完整H评价。
3. **固定漂移映射、只把更多辅助质量集中到目标U，不是可靠升级。** RA1最终完整H显示P-U50比P-small低1.8970pp，比同总替换质量的P-SYM25低2.2083pp，两项家族校正区间均为负。
4. **RA1前两次停止是数值求解未完成，不是业务负结果。** NR2在保持原目标与验收门的条件下完成困难参照，从而使完整比较得以成立。不能把NR1和NR2称为两轮独立分类成败实验。
5. **P-U50确实利用了新增映射U，但付出了其他训练视图和真实留出边界的代价。** 60角色中P-U训练CE全部改善、CORAL-U全部恶化；相对P-small，真实U访问新增15个错误、只修复7个。
6. **最小2×2将两个因素拆开后，只得到方向一致但仍不确定的证据。** 降低U替换、恢复C映射，点估计分别回升1.1234和0.9191pp，但四项预定比较的校正区间全部跨零，两个新点也均未超过P-small的点估计。

### 1.2 当前应保留的判断

\[
\boxed{\text{P-small仍是本阶段保留的有效参照，近期新候选未建立对它的可靠升级。}}
\]

同时保留局部证据：真配变换在某些同族对照中优于组级或直接入口补充；这些局部正结果不能替代相对强参照的整体增量，也不能因主候选不利而删除。

不能据此概括为“所有真实关联都没有价值”，不能说“修好求解器之后动态方法就应当获胜”，也不能将同一历史队列上的多轮结果视为多份独立外部反证。

## 4. 指标与统计：哪些分数可以比较

### 4.1 共同指标定义

- 每部署×遮蔽（有seed时再分seed）先合并外折，构造完整6×6混淆矩阵。
- F1_U取两个U类的F1平均，F1_C取其余四类；完整六类F1同时报告。
- 真实C误判入U会增加U类FP，不能丢掉C行计算“U二分类”。
- 各部署与遮蔽等权；神经实验按原规则再平均seed，不把概率集成为新模型。
- CE为真类负log概率；Brier为六类平方概率误差之和，未再除以6，范围0至2；均越低越好。
- C代价筛查为相对P-small总体最多1pp损害、单部署最多2pp损害；不是统计非劣效，也不是看过H后回退的许可。

## 6. DP-GAN1-M / Full NER1：逆向摘要恢复与矩约束

### 6.1 原科学问题

让一个post输入分支在推理中保留：先估计入口摘要，再由入口分类头给出概率，与冻结P-small融合。新增有限条件矩，检验恢复/关联知识是否提供强基座之外的作用。

虽然标识包含GAN，但实现**没有可训练判别器、随机噪声或极小极大更新，不是完整GAN**。

### 6.2 模型和损失

每块冻结逆Ridge G0从post标准化坐标预测raw pre，α=1，截距不惩罚；十块共1020个冻结估计参数。残差网络96→8→96 ReLU，无输出bias，共1544参数，输出层零初始化。

\[
\hat a=\Pi_{\mathcal H}\bigl(G_0(b)+r(S_B(b))\bigr),\qquad
p_{branch}=\operatorname{softmax}\bigl(W_AS_A(\hat a)+c_A\bigr).
\]

Π为每直方图块的欧氏单纯形投影，不是softmax或截断后归一化；只保证块内非负/和1，不保证真实协议会话、整数直方图或跨块物理可行性。

完整训练目标：

\[
\tfrac12 CE_w(h_A(\hat a),y)+\tfrac12 CE_w(h_A(a),y)
+L_{rec}+L_{fid}+L_{gap}+0.1L_{dev}
+\gamma(\|U_1\|^2+\|U_2\|^2+\|W_A\|^2).
\]

rec是raw恢复误差/10；fid使用部署×业务的一阶及原始二阶矩；gap约束C生成误差的目标—源差，不强迫真实pre域差为零。有限核为`aᵀc/10+(aᵀc)²/100`；这不是完整分布匹配或互信息估计。

| 分支 | 对应/目标 | 作用 |
| --- | --- | --- |
| R-P / R-G | 真配逆Ridge / 匿名组中心逆Ridge | 静态参照 |
| N-P | 真配动态恢复，不含fid/gap | 矩组合消融 |
| F-P | 真配动态恢复＋fid/gap | 主分支 |
| F-G | 匿名组恢复＋真实边际矩 | 粗对应控制 |
| E-post | post→post动态分支，无pre | post容量/优化控制 |

PURE为分支单独预测；FUSE为`(1−β)p_Psmall+βp_branch`，不是logit加和。所有FUSE共享已经含真实关联训练用途的P-small，故F-P−F-G只检验新增分支管线的差别，不是整个系统有无关联。

### 6.3 训练与执行修订

Adam固定2000步、独立clip=5。候选为lr∈{0.0003,0.001}×γ∈{0.0001,0.001,0.01}共六组；内层seed20261014，外层三seed20261014/15/16。最终生成器冻结，生成/真实侧各0.5w，凸分类头统一refit。融合β∈{0,0.25,0.5,0.75,1}仅在合法内层选择。

初始P1曾出现预算触顶漏拒绝、混lr桶与预算预计不合格。NER1修复这三项后，严格数值门保持；用户另将活动预算提高到40小时、保守预计门32小时，才进入Full NER1。旧停止记录保留，未将旧失败直接改判通过。

全数值CUDA float64，无AMP/TF32/CPU训练回退；动态阶段最多32模型、8 streams、CUDA Graph，凸头4并发且单lr分桶。

### 6.5 为什么不应把它概括为“没有训练起来”

全部最终凸头通过原梯度门。F-P在所选246条外层动态路径上的训练总目标均值0.600227→0.115933，raw恢复误差0.130669→0.099374，但pre标准化误差67.045986→820.385070。raw与std坐标赋权不同，不能用raw下降代替分类坐标保持；也没有H-pre可据此声称H恢复成败。

F-P-PURE在同一终态生成器上的CE：初始化头2.252195、Adam头3.647744、refit头3.664619。最后refit只造成较小变化，主要弱点不能全归于“凸头吞掉了收益”；这也不是允许事后改用初始化头的证据。

相对B0，F-P-FUSE在U的三seed逻辑行中修复4、新增43；相对F-G则修复48、新增12。前者解释整体不利，后者解释真配相对组级正结果。这里U行数1440是480访问×三seed，不能按1440个独立访问理解。

## 8. RA1：固定映射、改变C/U辅助替换分配

### 8.1 科学问题与模型

不再新增神经生成器或改变损失，而是研究：有真实目标C、没有目标U时，把已有漂移辅助视图更多放到U是否更合理？

固定P/G前向全仿射映射、CORAL、post尺度和逐角色t/η，只改变辅助视图的来源及ρ_C/ρ_U。最终模型始终是96→6线性softmax，名义参数582：

\[
J(W,b)=\sum_iw_iCE(Wx_i+b,y_i)+0.0005(1+t)\|W\|_F^2.
\]

bias不罚，L2作用于原W；不按训练行数再次除损失，不因RawPre尺度大而单独重新标准化或裁剪。

| 分配 | ρ_C | ρ_U |

| SYM | m | m |
| UPR | 0 | 2m |
| CPR | 2m | 0 |

m∈{0.1,0.25,0.5}，来源P/G/RawPre/RawPost各9项，加S、P-full、G-full共39政策。P为真配映射、G为匿名组映射；RawPre不变换入口视图，RawPost替换为源post作为曝光参照。
