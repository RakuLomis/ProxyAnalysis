# A–H机制链：论文证据整理

日期：2026-09-21。局部机制链结项；本节只使用冻结A–H结果，不把后续跨部署验证混入同一实验条件。

## 研究问题与权限

研究对象是0916保守六业务、240访问、30内容、SS/VLESS两个已见部署。五折按内容留出，同内容部署、重复、父访问与两侧整体移动。Full157维统计、固定线性源分类器，配对校准仅用于训练；实际post预测不读取测试pre或标签。

本链不是线上无索引流量识别系统：仍为offline_index_assisted_post。pre是代理会话入口观测，不是真实直连采集。模型不输入IP地址、端口、SNI等身份元数据，但离线对象选取与配对依赖采集索引。

## 统一方法与监督资源

| 臂 | 分类器训练标签 | 校准辅助资源 | 测试输入 | 主要问题 |
|---|---|---|---|---|
| A | pre业务标签 | 无 | pre | 入口分类能力 |
| B | 同一源模型 | 无 | post | 能否原样跨侧使用 |
| C | 同一源模型 | 精确pre/post配对，统计Ridge | post | 统计恢复能否帮助迁移 |
| D | 同一源模型 | 同内容同部署四重复循环错配 | post | 精确对应在原目标下是否有价值 |
| E | post业务标签 | 无校准 | post | 出口直接监督参照 |
| F | 同一源模型及其W | 精确配对，统计＋决策分数目标 | post | 改目标而非容量是否有用 |
| G | 同一源模型及其W | 同内容循环错配，同F目标 | post | 新目标是否仍依赖精确配对 |
| H | 同一源模型及其W | 内容×部署组中心，无组内实例匹配 | post | 组级对应能否提供任务用途 |

F/G/H的W携带业务监督，不是完全无监督方法。H也不是完全无配对，只降低了匹配粒度。已有精确配对时，pre标签可以传给post训练E，不能宣称C/F/H已被证明减少人工标注。

## RQ1：直接跨侧与统计校准

A/B/C/D/E的macro-F1依次为.954656/.455518/.768683/.645773/.908219。

固定源分类器从pre换post明显退化；统计校准C部分恢复，且相对D有优势。C−B的F1增益.313166，95%内容bootstrap区间[.246919,.381278]；C−D增益.122910，区间[.077734,.171855]。但C仍低于A/E，不能将重构关系解释为决策边界完整保持或代理变换可逆。

## RQ2：业务迁移是否受恢复目标限制

固定逐维仿射参数形式与源模型，新增中心化源logit平方损失。预定λ=1时F的F1=.853494、CE=.654916，相对C同时改善；F−C F1增益.084810，区间[.055233,.119480]。

G的F1=.865603、CE=.655022；F−G合并F1/CE区间均跨0。新增收益不能全部归因为精确访问对应。原C>D并未失效，而是对应关系的业务价值具有目标依赖。λ=.1/10只是已报告的敏感性，不把最有利值重新定为主设置。

统计MSE从C的.219979升至F的.373656，同时中心化logit MSE由3.732687降至2.439953。任务指标与完整统计恢复不是同一目标。物理范围违反也增加，适配向量不宜称物理合法的还原流量。

## RQ3：对应关系需要精确到单次访问吗

H仅以源训练内容×部署中心替换两项目标，保持λ=1和同一仿射容量；结果F1=.864561、CE=.623125。H−F F1增益.011067，区间[−.013492,.033561]；H−G为−.001043，区间[−.018468,.017018]。没有预定等效界值，所以不能宣称正式等效。

H留出统计MSE=.624033、logit MSE=3.711065，恢复精度低于F，却没有出现同比的合并业务损失。源训练组内四次访问的完整源预测类别全一致，但分数残差非零；该源模型在训练区100%正确，所以只能视为训练内描述，不能推广为测试重复一致。

部署例外必须保留：SS上H较F改善，VLESS上F的概率指标优于H。不能仅凭合并值判定精确对应不重要，也不能把H包装为整个研究过程导出的最强模型。

## 证据台账与写作边界

机器可读台账：`outputs/mechanism-evidence-0916/claim-ledger.json`，各条对比保留源文件路径、数值、区间和口径。来源封存记录见同目录`provenance.json`。详细条件仍以三份原报告为准：

- `docs/0916-source-classifier-cross-side-transfer-results.md`
- `docs/0916-source-decision-aware-calibration-results.md`
- `docs/0916-source-score-hierarchy-center-control-results.md`

论文可以写“直接跨侧退化→统计校准部分恢复→任务感知校准改善→对应粒度改变其用途”，不宜按教师、SSL、锚点、校准依次升级的开发流水账写。早期实验的不同任务和划分只能明确标注后作背景或补充材料。

共同限制：区间条件于已拟合模型、内容簇重采样、未校正多重比较；队列已经反复分析，方法具有回顾性选择影响。代码可追溯与连接审计不能取代外部验证。

未由本节验证：跨部署校准复用、真实直连→代理、单flow分类、无索引在线分段、新VPS/网络/日期/客户端泛化。跨部署是另一个固定方案的X实验，其结果应单独呈现并注明历史目标部署可见性，而非回写成A–H原本就有的能力。

本局部链条在此结项，不继续添加均值、donor或λ变体。

## 独立X验证完成后的证据台账补记

同日完成的X实验见`docs/0916-source-calibration-cross-deployment-results.md`，来源为`outputs/source-calibration-cross-deployment-0916/run-01/report/metrics.json`、`contrasts.json`及`audit/validation.json`。该实验重新仅用单一部署96条训练访问拟合全部预处理与模型，不改变以上A–H冻结结果。

新增证据：SS→VLESS的F/H未检出相对B的F1改善，但CE改善；VLESS→SS的F/H相对B有F1与CE收益。两个方向的入口诊断A均明显下降，限制不只来自出口校准。只能称历史已见两部署之间、拟合期隔离的方向性迁移验证，不称未接触目标部署的盲测或稳健普适泛化。

因此，“跨部署校准”由本节原先未验证，更新为另有独立且有限、方向不对称的验证；真实直连、单flow、无索引在线分段和新环境外部泛化仍未验证。
