# 关联表征、输出约束与完整联合适配：阶段性实验总结

截至日期：2026-10-16。项目：ProxyAnalysis。

范围：最近七组相互衔接的实验——post输入入口表征残差分支（Stage A）、固定G读出、温度校准、输出硬正交OR1、子块漂移诊断SD1、形状来源替换ST1和完整联合适配JAT1。尺度与梯度诊断、错误置信度分析和P3封存修复作为解释性证据纳入，不另算独立业务实验。

本文是新增的只读证据汇总，不修改原模型、预测、区间、资格门或停止记录，不启动新训练。它补充[截至10月14日的全研究阶段总结](F:/Program/VSCode/MyGit/ProxyAnalysis/docs/proxy-correspondence-stage-summary-20261014.md)，不是对0914、0916及全部历史研究的重新汇总。

## 1. 阶段结论

当前不能概括为“真实关联没有用途”，也不能概括为“恢复入口表征已经稳定改善分类”。证据应分成四层：

1. **统计预测用途仍然存在。** SD1中，冻结真配前向映射在多数部署×块单元具有描述性的形状预测优势。
2. **有限分类可读性曾经出现。** 固定G、放松实际输出正则后，源内U-F1提高约1.13个百分点，但修复集中于极少数内容与访问，并伴随概率质量恶化。
3. **硬保持或硬删除某个方向没有得到支持。** SD1没有找到需要把位置锁回pre的合格方向；OR1硬正交读出出现分类及概率退化。
4. **完整联合训练已经接受整体业务检验，当前程序结果不利。** JAT1完成全部外层H-post评价，主候选JP的U-F1为76.2220%，相对P-small的79.6931%下降3.4711个百分点，家族校正区间整体为负。

因此，P-small继续作为当前有效参照；最近新增方法分别按“未获源内资格”“有限正向但有代价”“整体不确定”或“明确不利”结项。不能把这些状态统称为同一种失败，也不能把共享历史内容的多轮结果当成多份独立外部验证。

## 4. Stage A：post输入关联表征残差分支

### 4.1 研究问题、结构与监督

问题是：训练时使用真实pre指导一个post输入分支，并在推理时保留该分支，能否超出冻结P-small？

教师为`96→16 ReLU→8线性瓶颈→6`，1742参数。用合法训练pre及业务标签训练，冻结后用合法训练pre瓶颈的加权均值/标准差确定八维目标坐标；标准差小于1e−8沿用scale=1。目标不是六维logit或one-hot。

G为`96→16 ReLU→8`，1688参数；拼接`[x;G(x)]`后通过`104→6`残差头，新增可训练参数共2318，原P-small的582参数冻结：

\[
\ell(x)=\ell_0(x)+0.1P_6\{V_xx+V_gG(x)+c\}.
\]

残差末层零初始化；分类训练时也用估计的G(post)，不向分类头提供真实pre表征。

| 臂 | 监督 |
| --- | --- |
| A0 | 原P-small，无新增拟合 |
| A1 | 仅CE，无pre表征目标 |
| A2 | 同内容同部署四重复pre表征均值 |
| A3 | 同次访问pre表征 |

A1为λ=0；A2/A3的λ∈{0,0.1,1}，零λ精确复用A1。固定1000步Adam、lr=0.001、clip=5、weight L2=0.01、bias不惩罚、三seed为20261014/15/16。教师固定1000步Adam、lr=0.001、weight L2=0.01。

### 4.3 尺度诊断提供的解释

固定12任务只读诊断显示：设实际修正权重D=0.1P₆V，则名义0.01头部L2对有效D对应系数1；相对同post坐标P-small的κ=0.0005(1+t)，强约400至2000倍。该比较不适用于bias或整个非线性网络。

A3、λ=1在这12任务中的G-MSE从起点约1.075降至0.141，但总logit修正RMS约0.01195，G分量约0.00580，864条重叠预测仅改变3次类别。第一步V=0导致CE对G零梯度是预期现象，后续任务梯度存在，不是梯度断开。

这支持受控检查读出尺度，不证明L2是唯一原因或放松正则必然有效。该历史子集CE/MSE梯度余弦为正，不能把后面JAT1的负余弦反填到本轮。

## 6. 温度校准：不撤销修复，能否缓解过度自信？

### 6.1 配置与新增标签成本

G、教师、分类器和原结果全部固定。对P-small及X/R/G/P两档η共九管线给予相同机会，学习完整logits的正标量温度：p=softmax(ℓ/T)，T∈[1,5]。

六query内容做全局留一内容交叉拟合；每角色每折仅用其余五内容、20次访问及合法标签拟合T。三seed共享T并等权，不跨角色共享数据。共12×9×6＝648个温度。每折只有五业务，留出第六业务不进入该T的拟合。

这是新增的源内标签校准成本，不是无标签或零拟合技巧。只接受旧logits/概率，没有重训G或分类器，没有实际H/U。使用CUDA float64、最多64次目标/导数评价；原始run-01的平坦目标接口测试停止保留，run-02仅修订该测试的不可辨识断言。

## 10. JAT1：完整联合训练与实际H评价

### 10.1 与此前的实质区别

\[

G仍为96→16→8、1688参数；完整W/V/c为630参数，全模型2318参数。W/c复制原P-small，V严格为0，G确定性随机初始化；没有冻结offset、0.1缩放、OR、LOC或W−W_initial锚定惩罚。

### 11.2 训练与推理接口的认识

早期前向漂移辅助用于改变训练材料，推理只执行最终post分类器；本组Stage A/JAT1则已让G(post)作为推理计算的一部分。后者仍未建立稳定新增收益，因此不能继续将失败唯一归因为“关联模块没有部署到推理端”。

固定模型后G(post)由post确定，不是额外真实pre观测，不解密，也不能凭空创造post中不可辨认的信息。训练pre的作用是塑造表示和归纳偏置，其任务价值必须通过同容量与组级等控制验证。

### 11.3 三类结果必须分别保留

1. **有限正向但有代价：** 固定G分类修复、温度对U过度自信的缓解、SD1形状预测用途。
2. **总体增量不确定：** ST1三项主比较、JAT1相对JC/JG/FR的差异。
3. **当前程序明确不利或不满足用途：** OR1、SD1位置硬保护、JAT1相对P-small及其C代价。

Stage A另属于“全源内未获资格、最终精确回退”的程序结果，不应伪装为实际H上新分支的负向试验。

## 12. 共同结论边界

- **不是外部盲测。** 多轮共享已被反复分析的历史内容；重新封存只能约束本轮执行顺序，不能消除研究者既往接触和回顾性选择。
- **不是完整学习程序的不确定性。** ST1/JAT1的内容簇区间条件于固定模型及已选配置，不包含重训、教师变化或重选参的全部变异。seed、角色、重复和合成行不增加独立内容数。
- **不是未见协议泛化。** 本组不支持AnyTLS、Hy2共享carrier、未见VLESS配置、跨日期或新VPS。JAT1有目标C配对校准，也不能称目标部署完全不可见。
- **不是物理不变量或信息量估计。** 直方图分解、梯度夹角、RMS、矩阵非加性均是特定表示和模型的诊断，不是互信息、因果贡献或语义解耦证明。
- **内容隔离不等于新完成绝对无泄漏证明。** 本轮未随机拆分父访问flow，继承原排他TCP资格和全局内容折；但未重新完成全局physical连接重建，仍有既有访问窗口及browser_quiescent依赖。不能把没有IP/SNI输入当作排除所有环境线索。
- **共享基座影响归因。** JC、组级和随机控制使用共同P-small分类材料，该材料本身已利用真实关联。控制回答新增模块的用途，不证明整条系统完全不需要精确对应。
- **工程通过不等于方法成功。** 原停止、修复和科学状态分别保留；数值充分性可以排除某类故障，不能替代留出业务评价。

## 13. 当前阶段的保留与停止决定

保留P-small作为当前有效业务参照；保留统计预测、少量分类修复和概率代价的完整证据。Stage A、固定G、温度、OR1、SD1、ST1和JAT1均按各自原合同结项，不覆盖旧结果或用后续实验倒改前轮资格。

没有授权或自动执行：GAN、扩大G、更多lambda/eta/温度网格、挑有利部署/内容、用H选择checkpoint、重定义FR或新增不变方向。本文不提出一个保证获胜的新候选，也不将局部诊断永久等同于所有完整方法的否决。

当前最稳妥的阶段性表达是：

> 真实代理关联具有可测的统计预测结构，固定关联表征在小范围合法源内任务中存在少量分类可读性，但其概率代价和可推广范围受到限制。硬位置保护与输出硬正交未显示当前用途；固定形状来源替换的业务增量仍不确定。允许完整分类器与关联分支共同适配后，预登记JAT1程序在完整内部H评价中明显弱于P-small，未建立新增精确身份监督或持续联合适配的独立收益。因此，本阶段保留既有P-small及测量成果，收束这些新增候选，而不推广为所有代理关联方法无效。
