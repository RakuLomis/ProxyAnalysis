# 0916 数据集与已完成实验：阶段性详细总结

更新日期：2026-09-17。数据集：`TrafficTracer-content-generalization-20260916`。

本文汇总截至本日期已完成的数据审计、特征提取、240 次访问主实验和 299 次访问敏感性实验。仅总结既有结果，不新增模型选择、统计检验或采集。0914 及更早数据未进入本文业务模型训练。历史报告中的“尚未训练”“等待 299 确认”等进度表述，以本文和 299 实验报告为准；历史数值不被覆盖。

## 1. 核心结论

0916 的主要进步是为每类业务登记五个不同内容，使我们能够按内容留出，检验未见资源上的业务识别，以及训练时使用真实 pre→post 对应关系是否改善仅使用 post 特征的预测。

目前形成的证据链是：

1. **数据可用，但不能把全部数据视为同质的三协议配对队列。** 原始批次包含七业务、三部署、525 次选定访问；正式业务实验限定为六业务、SS/VLESS。Bilibili 的播放标签得到用户确认，但主目标直连；Hy2 存在共享 UDP 载体及路由策略差异，未进入排他 TCP 主实验。
2. **已有可直接使用的处理后数据集。** 六业务 SS/VLESS 的 300 次访问完成两侧逐包特征提取；导出 pre、post、配对平铺特征表，以及三种包筛选口径的摘要。
3. **测试内容未进入训练；没有发现所审计范围内的原始连接跨会话复用泄漏证据。** 内容分组、教师训练排除、配对映射和预处理均有审核产物，但这不排除同批次环境混杂。
4. **真实对应关系的相对价值，并不等于单侧业务收益。** 六类任务中，真实 pre 教师监督的损失低于同业务错配监督，尤其 SS 的差异较稳定；但仍高于不使用教师的 post-only 基线。
5. **YouTube 同域播放/搜索任务尚无稳定配对增益证据。** 部分平均损失改善的内容级区间跨零，部分对照随教师分法变号，且损失改善不总伴随 F1 提升。
6. **299 次敏感性实验未推翻 240 次主实验的结论。** 它来自同一批次且与主实验重叠，不能当作独立外部验证，也不能将两者样本量相加。

适合当前论文表述的是：在当前特征表示、固定线性软标签学习方法和离线索引辅助观测条件下，保留真实配对显示部分对应依赖，但尚未建立稳定优于 post-only 的业务学习收益。

35 个目标中有 6 个 URL 在 0914 出现过。因此，虽然本轮模型仅用 0916 从头训练，也不应将所有内容称为此前从未分析过的完全盲测资源。

## 3. 标签有效、网络质量、配对可用必须分开

### 3.1 视频与 degraded 的处理

沿用用户确认：**有正片播放即可接受视频活动标签**，不将完成配置播放时长作为唯一门槛。degraded 表示某项执行或质量检查降级，不自动代表业务标签无效。

YouTube 的 75 次播放访问均有正片存在证据：

| 部署 | 观察到的最短正片时长 | 中位数 | 达到配置 25 秒目标 |
|---|---:|---:|---:|
| SS | 18.283 秒 | 40.033 秒 | 23/25 |
| VLESS | 41.486 秒 | 44.497 秒 | 25/25 |
| Hy2 | 42.218 秒 | 46.200 秒 | 25/25 |

SS 的两次 18.283/20.106 秒访问虽未完成目标，仍保留播放标签；Hy2 两次关键资源降级访问也存在约 47 秒正片播放。当前保守候选不是“一律去掉所有 degraded”。

Bilibili 已依据用户对五个目标正常播放的观察更新有效标签。其证据粒度是目标级人工观察，不是全部 75 次访问的逐次时长遥测。原始自动字段保留，人工确认以单独覆盖层记录。

### 3.2 为什么 Bilibili 暂未进入主模型

75 次 Bilibili 精确主目标请求均为 DIRECT。SS 的 25 次访问没有代理请求；VLESS 仅 7 次有附属代理请求，主要为 `i1.hdslb.com` 图片资源；Hy2 仅 1 次有少量附属代理请求。

因此排除原因是**不满足当前严格代理业务队列的路由口径**，不是认定视频没有播放。附属图片资源的少量代理连接不能替代完整视频活动经过代理的证据，也不能据此比较三协议对完整视频业务的变换。

### 3.3 为什么 Hy2 单列

- 共享 UDP carrier 不能直接套用一条逻辑 TCP 连接对应一条排他外层 TCP 连接的规则。
- Hy2 的 25 次 Bing 主目标均为 DIRECT。
- Hy2 的 YouTube 请求索引存在 445 条关联 UDP/h3 REJECT 策略的记录，另有 147 条代理关联记录。445 不是独立失败连接数，更不是播放失败次数或丢包率；某些请求最终仍返回 HTTP 200。

这些事实支持按部署策略解释，不支持归因于 Hy2 协议本身。当前没有完成与 SS/VLESS 主模型同口径的 Hy2 业务实验。

### 3.4 唯一暂不纳入的 MDN 恢复访问

MDN Overview、SS、第 3 轮出现 `NAVIGATION_TIMEOUT_RECOVERED`。最终 HTTP 200、URL 正确，存在 4 个排他 TCP 配对，但 navigation/activity 标记 degraded。

该访问不是已证实无效；它已保留在 300 次特征表中。按用户“现阶段采用较保守候选”的决定，它暂不进入 299 候选实验。未来可以研究恢复访问及其他降级情形，但目前尚未完成全 300 次模型实验或降级程度分层鲁棒性实验。

## 5. 已提取哪些特征，哪些进入模型

### 5.1 特征计算与样本粒度

当前业务学习以**一次访问为一行**，不是把包或同一连接的切片随机分到训练/测试。先对合格配对中的原始连接解析包，保持实体边界，再汇总为访问级两侧特征。

模型主输入使用 `observed` 口径，同时保存 `nonempty` 和 `exclude_full_retransmission` 摘要用于后续分析。计算使用项目自己的解析、方向、重传和特征算法，不依赖 Wireshark 内置统计结果。

### 5.2 模型的 14 个标量白名单

| 特征 | 当前实现含义 |
|---|---|
| `packet_count` | 所选包总数；observed 包括空载荷包 |
| `transport_bytes` | 传输层载荷字节总和，不是抓包文件大小 |
| `ip_bytes` | IP 总长度之和，是长度统计，不是 IP 地址 |
| `up_transport_bytes` | 正方向传输载荷总字节 |
| `down_transport_bytes` | 反方向传输载荷总字节 |
| `burst_count` | 原始实体内同方向连续段数量之和 |
| `fr_runs` | 各 TCP 实体的非空方向段数之和，对应 FR 首段计 1 的定义 |
| `fr_switches` | 各实体非空方向切换次数之和，首段不算切换 |
| `fr_runs_per_packet` | FR 段数总和 / 非空包总数 |
| `up_byte_fraction` | 正方向载荷字节 / 两方向载荷总字节 |
| `transition_p_pm` | 非空方向序列中，从正方向转为反方向的条件概率 |
| `direction_entropy` | 非空包方向比例的二元 Shannon 熵，单位 bits |
| `length_median` | 非空包传输载荷长度中位数 |
| `iat_median_us` | 原始实体内相邻所选包 IAT 的合并中位数，单位微秒 |

代码用 +1/−1 表示方向，与论文中的 0/1 是编码差异。FR 先筛选非空包，再在每个实体内部形成方向段。对包含非空数据的单个实体，FR 段数 = 切换次数 + 1；访问聚合后应加的是非空实体数，而不是全访问只加 1。

IAT、FR、burst 和转移不跨不相关连接边界构造。`direction_entropy` 是方向边际比例熵，不是转移条件熵或业务互信息。`transport_bytes` 含 observed 中观察到的载荷重复，不能自动等同去重后的应用有效字节。

### 5.3 已保存但未进入本轮模型的摘要

还保存了非空包数、实体数、固定边界长度/IAT 直方图（含尾部）、101 点归一化累计载荷曲线及部分诊断计数。这些可以支持后续分布和累计形状比较。

需要区分“代码支持”“本批次已提取”“已经做了实验”：本轮并未把早期需求表的所有特征族都投入模型，也没有在 0916 上完成一套新的 MAD/IQR/ICC、变换可分离性、跨 URL 同向性、JS/Wasserstein/KS、RTT、窗口、握手、CDN 变化的完整统计报告。不能把旧批次的这些结论移植为 0916 结论。

尤其不能仅凭本轮分类结果声称 SS 在 0916 普遍表现为“包数增加、burst 增加、字节稳定”。这需要另行汇总两侧特征变化；本文不虚构尚未完成的逐特征规律。

### 5.4 强指示信息与单侧观测边界

IP 地址、MAC、端口号、SNI、domain、路径、绝对时间、session_id、captured_bytes 派生量均未进入模型 X。它们可以用于标签、身份审核、方向确定、配对及内容分组；导出表保留元数据不等于模型使用元数据。

但测试流量范围由离线索引辅助界定，观测口径为 `offline_index_assisted_post`。学生预测函数只接收 post 数值矩阵，这证明的是**给定离线界定的访问流量范围时的单侧预测**，不证明未知混合网络流量上的在线业务分割已经解决。

## 6. 实验问题、模型和对照设计

### 6.1 两项业务任务

分别在 SS 和 VLESS 内运行，不把部署分类准确率作为业务收益：

1. 六类 domain × activity 分类：包含 30 个内容，但多数 domain 只有一种 activity，可能较大程度利用网站流量模板。
2. YouTube 内播放 vs 搜索分类：包含 10 个内容，控制顶层 domain 后更直接比较活动；仍不是纯语义因果实验。

### 6.2 外层留出与教师交叉拟合

五折外层验证：每折每类留出一个内容，同内容的所有重复及部署共用外层分组。训练每类四个内容，测试一个。没有将同一内容的重复随机拆到训练与测试来声称未见内容泛化。

教师在外层训练内容内两折交叉拟合，每类四个内容分为 2+2，预先固定三种分法。教师只为未见内容生成 OOF 概率；错配 donor 和 receiver 的内容均排除于对应教师训练集。

| 队列与任务，每部署 | 访问总数 | 每外层折训练 / 测试 |
|---|---:|---|
| 240 主实验，六类 | 120 | 96 / 24 |
| 240 主实验，YouTube | 40 | 32 / 8 |
| 299 实验，六类 VLESS | 150 | 120 / 30 |
| 299 实验，六类 SS | 149 | 受影响内容在训练时，119 可用匹配为 118 / 30；在测试时 120 / 29 |
| 299 实验，YouTube 两部署 | 各 50 | 40 / 10 |

299 实验在业务、部署、教师留出分区内保留两内容共同可用轮次，四个学生臂共享同一训练池，测试访问不因错配需要而删除。不是只从错配组去掉难样本。

### 6.3 四臂对照

| 组 | 训练信号 | 测试输入 | 要回答的问题 |
|---|---|---|---|
| M0 | 硬业务标签 | post | 不借助教师的基线 |
| M1 | 硬标签 + 同次 post 教师软标签 | post | 普通软标签监督能否解释收益 |
| M2 | 硬标签 + 真实对应 pre 教师软标签 | post | 训练期利用真实双侧对应是否有用 |
| M3 | 硬标签 + 同业务跨内容错配 pre 教师软标签 | post | 精确对应是否优于同业务但不对应的监督 |

M3 保持部署、业务标签、重复轮次、教师留出分区一致，只交换内容；映射双射、无自配。240 主实验还运行同内容跨重复错配，使用五个预设映射种子。299 敏感性未重复该补充控制。

教师与学生均为 LogisticRegression：C=1、最大迭代 3000；训练内中位数填补和标准化；T=1、α=0.5。软目标为 `0.5 × one_hot(Y) + 0.5 × teacher_probability`。没有依据新结果挑选最优参数或教师分法。

另有 pre-only 教师诊断，它使用测试 pre 特征，是单独诊断，不是学生单侧推理的一部分。

### 6.4 指标与不确定性

主要比较 log-loss / cross-entropy（CE，bits，越低越好），同时保存 macro-F1、balanced accuracy、Brier 和混淆矩阵。

- `G_task = CE(M0) − CE(M2)`：真实配对相对 post-only 的任务收益。
- `G_pair = CE(M3) − CE(M2)`：真实对应相对错配的收益。
- `G_soft = CE(M1) − CE(M2)`：真实 pre 教师相对普通 post 教师的收益。

正值均表示 M2 损失更低。三者不能互相替代：G_pair 为正不保证 G_task 为正。

区间先在内容内平均重复，再在各类别内部按内容重采样 2,000 次，保留组间配对。299 指标采用内容等权，避免有四次访问的内容权重小于五次访问的内容；另存访问等权结果。240 中各内容访问数一致。

这些是条件于已拟合模型的内容 bootstrap 区间，不是每次 bootstrap 都重训练，也不是跨环境总体区间。没有将未经多重比较处理的多个区间当成全面显著性发现。

### 7.3 教师分法与补充对照

三种预设教师分法下，六类 SS 的 G_task 为 −0.0632 至 −0.0561，VLESS 为 −0.0931 至 −0.0671，均未胜过 M0。YouTube SS 为 0.0179 至 0.0248，VLESS 为 0.1109 至 0.1677，但 VLESS 的 G_pair 在 −0.0332 至 0.0434 间变号。

主教师分法中，同内容跨重复错配相对真配的损失差，五个映射种子的描述性均值为：六类 SS 0.0598、六类 VLESS 0.0312、YouTube SS 0.0669、YouTube VLESS 0.1528 bits。该对照改变重复轮次；主跨内容错配保持轮次，不能将两者差值视为纯内容效应和纯时间效应的因果分解。

pre-only 全训练侧教师诊断的 F1 依次为 0.9585、0.8481、0.9499、0.7749。它们说明 pre 特征具有预测结构，但该教师每类见四个内容，生成软监督的交叉拟合教师每类仅见两个内容。前者更强不保证后者能向学生传递有益信号。

## 10. 与信息论及论文主张的关系

CE 差以 bits 表达，只说明在当前预测器及评估口径下预测损失不同。它不是自动成立的真实互信息估计，更不直接等于条件互信息。真实配对与错配的学生都受到标签、有限样本、正则化和教师质量影响，模型损失差不能直接解释为信息论上的纯对应信息量。

当前没有证明：

- pre→post 变换可逆，或能恢复原始通信内容；
- 协议因素与业务语义已解耦；
- 所有配对学习方法无效；
- 当前部署差异就是纯协议机制因果效应；
- 完全无需离线索引的在线单侧业务识别已成立。

0914 的部署预测与配对价值实验提供研究动机；0916 的贡献是把问题推进到未见资源的业务任务，并实测其单侧利用边界。不能将旧批次部署分类 F1 或变换规律记为本批次新结果。

论文可使用的保守总结：

> 在 0916 的六业务 SS/VLESS 严格配对队列中，基于流量标量特征的跨内容业务识别具有可预测性。训练期使用真实 pre→post 对应关系，相比同业务跨内容错配监督表现出部分损失优势，尤其在 SS 六类任务中较稳定；但该优势尚未转化为稳定超过 post-only 基线的业务收益。YouTube 同域活动任务的结果仍受内容样本量和教师分法影响。结论限于当前部署、表示、固定学习方法及离线索引辅助的观测条件。
