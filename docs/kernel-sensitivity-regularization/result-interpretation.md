# 核敏感度正则结果解读

本轮完成已登记的嵌套内容评价。真配核正则的12项主比较中，1项校正区间完全大于0，0项完全小于0；其余区间包含0。KSR2在20个外层部署折角色中有6个选择零权重。

若某部署仅有点估计改善或区间包含零，不能升级为该部署已建立额外收益；也不能把不同臂选择不同t的结果全部归因于矩阵方向。

唯一通过12项家族校正的是VLESS的KSR2减KSR4：F1差0.046128，校正区间[0.004929, 0.116859]。KSR2在四部署中的等权平均F1为0.814133，公平调参L2为0.812449，差约0.168个百分点；该平均差不是预登记的额外显著性终点。各部署的KSR2对L2及组级核比较均未通过校正，当前不能声称精确配对已带来独立业务增量。

收益也不是全指标一致：合并CE为KSR2的0.778291对L2的0.761202，Brier为0.302104对0.299842，L2更低。相对L2，KSR2在SS修复0例而新增1例错误，VLESS修复3例、新增1例，Trojan修复1例、新增2例，VMess修复1例、新增0例。这里描述的是同一冻结测试预测上的翻转，不是新机制因果证明。

VLESS的YouTube搜索recall仍为0.70，与原固定LR相同，低于调参L2的0.75。不能把VLESS总体改善解释成该困难业务已经获得改善。
