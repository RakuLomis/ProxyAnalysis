# CUDA 确定性计数修复说明

2026年10月5日，首个内层核计算在严格确定性模式下停止：PyTorch 2.5.1 的 CUDA 加权 `bincount` 没有相应确定性实现。当时尚未生成任何真实内层核、正则矩阵或正权重分类模型，已完成的20个零权重重放不受影响。

修复将加权计数改成 CUDA float64 的 one-hot 矩阵与权重向量乘积。这是同一加权频数公式的确定性求和实现，不关闭确定性、不改变成员、质量、平滑、候选强度、优化上限或数值容差。人工测试增至20项；所有测试通过后才重新开始内层计算。

原代码、原封存契约以及新旧源文件 SHA 保留在 `outputs/kernel-sensitivity-regularization-20261005/run-01/manifests/engineering-repair-01`。当前机器契约包含这次工程修复的显式附记，未静默覆盖失败记录。外层阶段仍需与冻结旧核重放计数及概率；若出现超出原容差的差异，必须停止，而不能调宽标准。

该修复只解决工程执行条件，不是方法效果的证据。分类收益和负结果应以独立的最终业务评价为准。
