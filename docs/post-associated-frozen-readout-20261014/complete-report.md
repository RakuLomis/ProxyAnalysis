# 固定G读出的输出尺度与业务增量实验报告

日期：2026年10月14日。本轮按修订版计划完成P0至P4，状态为`source_frozen_readout_complete`。所有新增训练均为合法源内的小型读出头，实际H/U没有读取或评分。

## 1 结论

本轮完成240个充分求解的头部、288个逻辑端点和6912条源内query预测，全部通过数值、权限和重放核验。G、入口教师、P-small、数据划分与历史180项回退均保持不变。

结果清楚区分了三个层次：

- **输出尺度发生预期变化。**真配读出的正则η从1改为0.01后，总logit修正RMS由约0.01195增至0.61441，G分量由约0.00580增至0.30856。原头部输出幅度限制确实可以被解除。
- **出现有限的业务决策可读性。**真配Reference的源内F1_U由基座0.692030升至0.703329，提高约1.13个百分点；同尺度x-only和随机展开没有改变分类类别。不能把本轮简化成完全没有分类收益。
- **未通过预定联合推进标准。**真配Reference的CE_U由1.192419升至1.308022，Brier_U也恶化；相对同尺度x-only、随机展开的CE更差，相对组级的CE改善又不足0.002。因此不进入全角色策略或实际H评价。

最稳妥的更新是：现有估计表征中存在少量可以被读出的业务决策结构，但放松输出正则同时使大量剩余错误更加自信。解除幅度压制不是足以保证泛化收益的修复，精确对应的新方法贡献仍未达到本轮登记标准。

## 3 目标与数值实现

基座ℓ₀保持原float64输入与计算。头部直接坐标为原标准化post经float32再提升为float64，G在CUDA float32上计算后提升为float64；不重新标准化。

\[
\ell=\ell_0+D\phi+e,\qquad
L_\eta=CE_w(\ell,y)+\eta\|D\|_F^2.
\]

X的φ为96维x，其他三臂为104维[x;G(x)]。共同类别分量用固定六行五列正交基Q消除，D=QA、e=Qb，\|D\|²=\|A\|²；bias不惩罚。自由参数分别为485和525，未扩大网络。

两项固定政策全部评价：Strong η=1；Reference η=0.01。它们是新的受控头部目标，不改写旧训练或门限，也不按query分数选择最佳η。G的MSE及自身L2为对头部参数的常量，不参与更新。

使用Pytorch312、CUDA float64 LBFGS、strong_wolfe线搜索，零初始化。统一max_iter=2000、max_eval=10000，目标独立重放误差≤10⁻¹⁰，原D/e坐标最大梯度≤10⁻⁵。不使用AMP、TF32、CPU训练回退或额外求解后端。

零修正基座恒等、共同分量与L2几何、bias无惩罚、独立目标及梯度、有限差分和权限负例均通过。旧float32头到新float64求和的最大舍入差约1.2641×10⁻⁸，仅单列为数值路径差异，没有将其计为业务变化或放宽旧门。

### 7.3 为什么F1上升但CE变差

P-Reference的U评价共有288条重复任务预测，其中：

| 基座→新预测 | 计数 | 平均ΔCE | 平均最大类别概率变化 |
| --- | ---: | ---: | --- |
| 正确→正确 | 189 | −0.033649 | 0.8542→0.8795 |
| 错误→正确 | 5 | −0.092089 | 0.4997→0.5177 |
| 错误→错误 | 94 | +0.426745 | 0.7635→0.7994 |

少量接近边界的错误被修复，产生F1正向变化；更多保留错误的真实类别概率降低，最大预测概率反而提高，损失增量压过了正确样本上的改善。

该分解直接支持“剩余错误更加自信”，而非仅根据CE均值猜测。它不证明原因唯一是L2，也不自动授权温度缩放、概率校准、删内容或更换损失。
