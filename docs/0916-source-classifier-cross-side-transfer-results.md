# 0916源分类器跨侧迁移实验报告

日期：2026-09-19。状态：主线T0–T10完成；R4冻结读出与flow资格支线未启动。

## 1. 核心结论

固定训练pre上的分类器，在留出内容的post上直接使用会明显退化；利用训练期真实配对进行逐维Ridge校准，能够恢复一部分业务分类能力，而且Full的真实配对优于同内容跨重复错配。但恢复不完整，也不普遍适用于每个单独特征组。

| Full实验臂 | macro-F1↑ | CE bits↓ | Brier↓ | BA↑ |
|---|---:|---:|---:|---:|
| A：pre训练，pre测试 | 0.954656 | 0.243980 | 0.078534 | 0.954167 |
| B：同一源模型，直接post | 0.455518 | 4.854757 | 0.899599 | 0.470833 |
| C：同一源模型，真配校准post | 0.768683 | 0.926380 | 0.323124 | 0.770833 |
| D：同一源模型，错配校准post | 0.645773 | 1.196222 | 0.431176 | 0.650000 |
| E：post训练，post测试 | 0.908219 | 0.523369 | 0.161089 | 0.908333 |

本轮支持的表述是：**在两个已见部署、固定统计表示与固定线性源分类器下，训练期精确访问对应具有post→pre校准价值，使源分类器在post观测上部分恢复业务预测能力。** 不能据此声称变换可逆、未见部署泛化、全面保持分类边界，或已经降低人工标注成本。

## 2. 数据、划分与观测权限

仅使用0916保守六业务队列：240访问、30内容，SS/VLESS各120访问，重复1/2/4/5。业务为Bing搜索、MDN文档、GitHub仓库、Wikipedia文章、YouTube搜索及视频播放；每业务40访问。

沿用五折内容划分，每折192训练访问、48测试访问，对应24训练内容与6测试内容。同内容的两种部署、全部重复、父访问内连接和两侧流量整体分折。没有随机拆flow，没有另设测试早停或超参数验证集。每个访问只贡献一次OOF预测，每个配置合计240条。

本轮核验各折内容/访问/capture成员隔离及旧连接身份审计来源，未发现重叠。它不是重新扫描全部原始PCAP的独立审计；历史来源哈希及旧产物完整性均通过。

B–D只接收post统计，测试pre仅用于A以及离线恢复误差/边界评价。先完成并封存B–E，再读取独立A输入包。模型不输入IP地址、MAC、端口、SNI、域名、内容ID或部署ID；这些元数据只用于分组和审计。特征ip_bytes是字节量而非IP地址。仍保留offline_index_assisted_post边界：统计对象的离线选择依赖既有索引，不等于已验证纯在线部署。

两部署均参与训练，因此这是已见部署内的留出内容迁移，不是跨部署留一或未见协议泛化。0914、Hy2、Bilibili及299扩展队列均未加入。

## 3. 模型与坐标约定

每折、每集合拟合一个多类LogisticRegression：lbfgs、L2、C=1、max_iter=10000、tol=1e-8、无class_weight。CPU、float64、单线程，环境Pytorch312；没有新增CUDA/神经训练，也没有搜索权重、特征组合、温度或分类阈值。

A–D严格共用源分类器参数与类别顺序。C/D复用旧一维逐特征Ridge（alpha=1、含截距），而不是新多输出/跨维回归。真配是同次访问pre/post；错配为同部署、同内容四重复循环1→2→4→5→1，保持双射且无自配。错配不是不同业务负例，也不是独立条件重采样。

源预处理T−仅以训练pre拟合median填补及StandardScaler；旧post预处理T+和旧pre目标归一化U−保留各自训练统计：

```text
A: raw_pre  → T− → 源有效列处理 → h−
B: raw_post → T− → 源有效列处理 → h−
C: raw_post → T+ → 真配Ridge → U−逆尺度 → T− → 源有效列处理 → h−
D: raw_post → T+ → 错配Ridge → U−逆尺度 → T− → 源有效列处理 → h−
E: raw_post → T+ → h+
```

未把两个标准化空间直接混用，也未以测试post重新标准化。测试raw_post从冻结来源表重新导出，不由已填补标准化数据反推。单组只使用自身坐标，不借用其他组的观测值。

五折源有效维度均为149/157，无效/常数坐标在A–D统一置源标准化0。索引31（length_p_17）在训练pre无变化、post有变化，E仍可利用自身post坐标，不能假定E与源迁移具有完全相同的有效信息空间。源全部有效坐标均有旧Ridge覆盖。

## 8. 分类边界保持与物理范围

以A的最强竞争类别k_A为固定对手，按线性源模型精确分解：

`Δmargin = (w_y − w_kA) · (z_C − z_A)`。

1680个访问—集合组合的最大代数核验误差为1.42e−14。Full有87/240访问在C中更换最强竞争类别，因此固定对手分解不能冒充C的真实最小margin变化。

| 组 | 全240访问平均贡献 | A正确而C错误的47访问平均贡献 |
|---|---:|---:|
| G1 | −.012090 | +.020301 |
| G2 | −.057673 | −.044843 |
| G3 | −.108505 | −.068327 |
| G4 | −1.363545 | −2.307261 |
| G5 | −.308716 | −.857580 |
| G6 | −.098322 | −.140577 |

在该固定模型和坐标下，G4是最大的平均负向贡献，G5其次。这是有符号的代数分解，不是因果重要性，也不是删组后重新训练的结果；不据此直接选组或改权重。完整访问结果与旧U−坐标恢复MSE均已联结，Full平均MSE=.219979，47条受损访问均值=.247658，不能仅凭这两个均值断言误差与错误的完整关系。

按各折训练pre margin四分位点划分留出A margin，四桶分别有94/51/44/51访问，A正确数83/51/44/51，C正确数54/44/40/47。边界较弱桶损失更集中；分位点没有在测试集上重新选择。

逐维Ridge没有联合物理约束。Full/C中31访问出现负坐标，209访问出现应在[0,1]坐标越界，240访问出现曲线非单调，240访问直方图和不严格为1（阈值1e−9）；Full/D对应11、13、238、240。这些是“至少一次违反”的访问计数，不代表每条曲线有大幅违反，也不衡量违反幅度。本轮没有截断、重归一化或单调投影，不能把校准向量称为完整合法的还原流量。

## 11. 结论边界与下一确认点

本轮建立了“源侧有能力→直接迁移受损→真配校准部分恢复→优于同内容错配”的业务对照链，但只在Full及当前固定配置下完整成立。高恢复skill不是高业务价值的充分条件；每组单独使用、Full联合使用、相对错配、相对直接迁移是不同问题。

C使用pre标签训练源分类器、训练期两侧真实配对拟合数值映射；当前配对也允许把pre标签直接赋给post训练E，所以没有证明人工标注更省。它演示的是固定源分类器、不再拟合post业务头的使用方式，而非无目标数据、无配对迁移。

数据已经被反复分析，区间条件于固定模型，尚无新采集外部验证；不能用审计代替外部验证或消除回顾性选择影响。

按批准计划，本轮在T交付处停止。未自动启动R4冻结读出、flow分类、输出物理投影或新映射/权重搜索。若继续研究迁移主线，后续应单独冻结一个针对“分类边界未保持”的受控方法对照，并保留B/C/D/E，而不是据本轮测试结果直接挑G4组合；若需要解释R4或转向flow，应分别确认原计划R/F支线。
