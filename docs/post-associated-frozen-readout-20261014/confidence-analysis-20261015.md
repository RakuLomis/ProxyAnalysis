# 固定表征读出的分类提升与概率恶化分析

日期：2026年10月15日。

## 1 主要结论

F1提高和CE、Brier恶化并不矛盾。本轮真配弱正则读出修复了少量接近边界的错误，但同时增大了大量剩余错误的置信度。按全部U评价行加权，剩余错误带来的CE增加为 **0.139285**，正确保持和错误修复合计只抵消 **0.023681**，最终CE_U净增加 **0.115604**。

这不是新增错误数很多造成的：真配η=0.01在U没有新增错误。主要问题发生在类别完全没有修复的访问上。

现有结果支持优先验证一种不改变类别排序的概率校准，而不是立即重训G、再放松L2、缩小整个残差或者加入GAN。对最终六类logits统一除以正标量T，可以在数学上保留当前全部分类决策和错误修复；是否能在留出内容上改善概率质量，仍须独立交叉拟合验证。本次没有拟合T，也没有生成校准后的成绩。

### 3.3 为什么平均真实类别概率提高仍不足够

六类Brier可以精确写成：

\[
B(p,y)=\sum_kp_k^2-2p_y+1.
\]

真配η=0.01在U上，平均真实类别概率实际上增加约0.013095；但概率集中项的增加更大：

\[
\Delta B_U
=\underbrace{0.038998}_{\Delta\sum_k p_k^2}
\underbrace{-0.026189}_{-2\Delta p_y}
=0.012809.
\]

总体上概率分布变尖了，增加的集中度并没有被足够准确地分配给真实类别。CE使用负对数而不是平均真实类别概率；少量真实类别概率已很小的错误继续恶化，也会抵消许多高概率正确预测的小幅改善。这解释了平均p_y、类别修复和CE/Brier可能朝不同方向变化。

## 5 残差尺度与L2如何参与这一现象

头部优化的是带权训练CE加输出坐标中的L2，不是留出概率校准误差：

\[
\ell=\ell_0+D_xx+D_gG(x)+e,
\qquad L=CE_w+\eta\|D\|_F^2.
\]

η从1改为0.01，惩罚强度降低100倍。真配头的训练CE由0.114301降至0.087717，留出总修正RMS由0.011946升至0.614412，G分量RMS由0.005798升至0.308560。修正头确实更充分地使用了输入，但训练目标不保证它在未见内容上保持概率校准。

为区分“改变类别方向”和“放大原分数”，对每个访问的logits先去掉共同类别分量，记原分数为s，新分数为s+δ，进行描述性正交投影：

\[
\delta_{\parallel}=\frac{\langle\delta,s\rangle}{\|s\|^2}s,
\qquad \delta_{\perp}=\delta-\delta_{\parallel}.
\]

| η=0.01读出 | 沿原分数方向的修正能量占比 | 投影缩放系数中位数 |
| --- | ---: | ---: |
| 仅x | 97.82% | 1.1437 |
| 随机表征 | 97.82% | 1.1441 |
| 组级表征 | 89.74% | 1.1565 |
| 真配表征 | 91.62% | 1.1602 |

所有评价行的径向投影系数都大于1，表明修正普遍含有沿既有logits方向的正向放大。仅x和随机表征尤其接近这种放大，因而可以显著改变CE/Brier而完全不改变argmax。

这个分解不是把91.62%的业务变化“因果归因”为温度，也不是说明剩余8.38%都是有用信息。它只是几何证据，提示应先将分数尺度与类别方向分开验证。投影系数依赖原分数，不能据此生成需要真实类别或测试pre的逐访问校准器。

数值求解本身已充分通过原验收，所有240个头部均通过驻点和目标重放核验。现有证据更符合“训练读出尺度和留出概率不匹配”，而不是“头部根本没训练好”。也不能据此将L2视为唯一原因：小样本、内容偏移和表征误差仍可能共同参与。

## 6 保持分类收益的校准为什么值得验证

对最终logits整体应用一个正标量T：

\[
p_T=\operatorname{softmax}(\ell/T),\qquad T>0.
\]

它严格保持类别排序，因而可以保留同一模型的混淆矩阵、F1、修复错误和新增错误。必须缩放**完整最终logits**，不是只缩放残差；后者会改变方向，可能撤销已有修复。也不应另行输出旧硬标签、却让概率的argmax变成另一类。

温度缩放是一种已有的一参数校准方法；相关文献支持方法形式，不提供本流量队列的成功保证。[Guo等，On Calibration of Modern Neural Networks，ICML 2017](https://proceedings.mlr.press/v70/guo17a.html)

本次只计算未改变预测时T=1处的解析导数：

\[
\frac{dCE}{dT}\bigg|_1=\ell_y-\sum_kp_k\ell_k,
\]

\[
\frac{dB}{dT}\bigg|_1=-2\sum_k(p_k-y_k)p_k(\ell_k-E_p\ell).
\]

| 模型与范围 | CE对T的导数 | Brier对T的导数 |
| --- | ---: | ---: |
| 基座，全部 | -0.431002 | -0.042570 |
| 真配η=0.01，全部 | -0.581320 | -0.052974 |
| 真配η=0.01，U | -0.904189 | -0.105923 |
| 真配η=0.01，C | -0.419885 | -0.026500 |

在已观察预测的局部，温度略微增大同时有降低两种损失的方向依据。正确保持组的导数却为正：变平会降低它们的置信度并付出损失；错误保持组的负导数贡献更大。校准是在两者间作统一调整，不是知道哪些访问错误后再单独降温。

基座自身也有同方向问题，因此后续必须同时校准基座与X/R/G/P。只将校准后的真配模型与未校准基座比较，会将一般校准收益误写为精确关联收益。局部导数不等于已找到T、不保证留出内容改善，更不保证校准后真配能优于同尺度控制。
