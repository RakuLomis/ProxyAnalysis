# 0916可靠特征组锚点实验：实施与结果

日期：2026-09-19。状态：首轮P0–P10完成；285个正式训练阶段、六次工程训练、5960次可靠性回归完成，独立审计与210项测试通过。未启动YouTube专项或0914扩展。

阶段结论：多个特征组的跨侧简单可预测性确实很强，尤其字节规模和累计形状；但本版“post自监督＋可靠性加权预测pre统计”尚未把这种结构优势转化为明确的业务分类增益。不能据此否定全部配对学习，也不能把结构可预测性写成已证实的业务收益。

## 1. 本轮要回答的问题

本轮不单独强调FR，也不假设所有特征代理前后相等。核心问题是：训练侧可识别的、跨代理关系可靠的统计结构，能否作为辅助预测锚点改善post-only业务识别？如果改善，来自增加辅助任务、可靠性加权，还是同次访问的精确对应？

采用最小实现：保留原有157维输入和编码器，以分组预测目标组织损失，不引入新的多分支编码网络。不能把本轮解释成已经穷尽锚点网络或配对学习的方法空间。

## 2. 数据、任务与观测边界

- 仅0916保守六业务队列：240次访问、30个内容、SS/VLESS两个已见部署。
- 六类为Bing搜索、MDN文档、GitHub仓库、Wikipedia文章、YouTube搜索、YouTube视频播放。
- 每类5个内容；每内容两部署，每部署4次重复：1、2、4、5。
- 五折按内容留出，每折192次训练、48次测试；同内容所有部署、重复及两侧随组移动。
- 无独立验证集、无测试早停、无测试侧无标签预训练。
- 本轮不使用0914、Hy2、Bilibili或299扩展队列，不补采。
- 推理仅用post统计输入，但连接集合沿用离线索引辅助筛选，口径仍为`offline_index_assisted_post`。不是已证明可无索引在线分段的系统。

业务标签用于沿用平衡内容划分以及下游监督；不进入可靠性映射的输入/目标、不进入VICReg或锚点预测损失。内容ID用于错配和分区，不进入分类特征。

## 4. 可靠性估计

### 4.1 训练侧四折交叉拟合

每个外层训练集有每业务4个内容，按内容排序确定四个内层折，每次留出每业务1个内容。部署、重复与两侧整体移动。每个内层训练144访问，留出48访问。

每维固定一维Ridge映射：同名post特征预测同名pre特征，alpha=1。post输入和pre目标分别仅使用内层训练统计做归一化；缺失目标不参加该维回归/评分。目标近常数或全缺失维度跳过，方差阈值1e−12。

参考预测为内层训练pre均值。不能使用留出pre均值作为参照。真实与错配关系分别计算；不使用跨特征映射、业务类别或部署ID预测pre。

按组内维度平均、每内容重复平均、再跨内容平均计算误差，并在SS/VLESS内分别评分：

```text
skill(g,p) = 1 - MSE_prediction(g,p) / MSE_training_mean(g,p)
reliability(g) = max(0, min_p skill(g,p))
weight(g) = reliability(g) / sum_g reliability(g)
```

参照误差无效则该组可靠性为零；所有组为零则停止。不是通过很小的分母制造高分。该分部署评分减少仅由两部署中心差异产生的虚高，但不声称排除了全部内容/负载混杂。

### 4.2 已完成的可靠性结果

五折真实配对和五折错配均通过至少一组可靠的门槛。实际进行5960次Ridge拟合，低于6280上限；每个外层折/关系596次，8个目标维度在每个内层折因近常数/缺失被排除。

独立审计重新用训练源特征和闭式Ridge公式重建5960组系数/预测，不调用额外sklearn回归；与记录预测的最大差异为1.4210854715202004e−14。另验证组内维度顺序置换不影响评分。

## 5. 模型与优化

主编码器：`157 → Linear(64) → ReLU → Linear(32)`。投影头：`32 → Linear(32) → ReLU → Linear(32)`。无BatchNorm、Dropout。

锚点臂增加六个线性预测头`32 → d_g`。输入为未掩码post表示，目标为训练pre标准化统计。pre目标缺失/近常数维度按掩码忽略。

```text
L = L_VICReg(post_mask_view_1, post_mask_view_2)
    + sum_g weight(g) × SmoothL1(predicted_pre_group, paired_pre_group)
```

VICReg权重25/25/1、方差epsilon=1e−4；两post视图独立掩码5%已标准化维度。辅助lambda=1、SmoothL1 beta=1。每访问组内有效维度平均，再对有目标访问平均。

正式训练各阶段1000步，全批量Adam lr=.001；CPU、float64、单线程、确定性算法；随机种子20260918/19/20。下游微调为硬标签CE加weight L2=1e−4，不惩罚bias。

每个SSL checkpoint独立执行：

1. 冻结编码器，在训练post表示上重新拟合StandardScaler和线性探针，LogisticRegression C=1、max_iter=10000、tol=1e−8。
2. 从同一SSL checkpoint出发，重新初始化业务分类头，微调编码器和分类头。不能接着使用探针的分类头。

推理移除投影头和所有pre预测头，只保留post预处理、编码器和业务分类器。

## 6. 七臂对照与错配规则

| 臂 | 方法 | 解释 |
|---|---|---|
| R0 | 无预训练，post监督 | 普通监督基线 |
| R1 | post自身VICReg | 一般post自监督 |
| R2 | pre/pre与post/post交替侧内VICReg | 增加pre分布资源 |
| R3 | post自监督＋等权组预测真实pre | 分组辅助目标 |
| R4 | post自监督＋可靠性加权预测真实pre | 预先指定的主方法 |
| R5 | 复用R4真实权重，但预测错配pre | 给定同一锚点先验的逐实例配对作用 |
| R6 | 错配关系重新估计权重，再预测错配pre | 完整真配与错配流程 |

错配为同部署、同内容的重复循环1→2→4→5→1；无自配、双射、两侧边际不变。内层训练与留出各自独立构造donor，没有从训练区给验证样本提供donor。

R5确实使用过真实关系估计出的组权重，不能称完全未使用真实配对的控制。R6用于补齐这个边界。错配不是显式对比学习负例，也不是任意不同业务噪声。

R3–R6具有相同编码器/投影头/预测头初始化、更新步数及前向暴露次数；每步两次掩码post和一次未掩码post编码。R1/R2每步仅两侧视图编码，因此不能把全部七臂都称严格等计算。

较准确的当前解释是：辅助目标可学，结构可靠性也真实存在，但这些约束偏好的信息未必正好是业务判别所需信息。逐次访问的形状、负载和时序细节可能比同内容重复共有成分更容易被预测，却不一定更利于跨内容业务识别。这是待检验的机制假设，不是本轮已经识别的因果机制。

## 9. 预先规定的判读边界

- R4优于R1但不优于R2：不能排除额外pre数据资源解释。
- R4不优于R3：未证明可靠性加权比等权分组目标有增量。
- R4优于R5：支持给定相同锚点先验下，同次配对的作用。
- R4优于R6但不优于R5：优势可能来自可靠性估计，不全来自训练时逐实例对应。
- 预测pre统计更准但业务无收益：可靠结构未必契合业务判别，不算完成业务闭环。
- CE改善但F1不改善：概率质量收益与分类决策收益分开报告。
- 微调改善、冻结探针不改善：不直接称表示更线性可分。

所有区间采用业务分层的内容级配对bootstrap，2000次；同内容跨部署和重复一起抽样，先计算每seed指标再平均。不平均概率形成集成。区间条件于已训练模型，未作多重比较校正，属于回顾性描述性证据，非外部确认性验证。

本轮决策：保留“可靠结构锚点”作为已验证可构造的机制，不将当前R4升级为有效业务方法。不自动扩大模型、搜索lambda或继续跑0914/YouTube来寻找正结果。下一步若继续，应先批准一个范围受控的“结构可靠性与业务相关性是否错位”的诊断方案，再决定是否改变目标或架构；当前结果尚不足以直接选定新方法。
