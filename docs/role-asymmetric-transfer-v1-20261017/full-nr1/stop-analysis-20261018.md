# RA1 Full NR1：再次停止的原因与进度分析

日期：2026-10-18。状态：**完整实验未完成；数值验收停止；没有新的 H 业务结果。**

本报告只读取既有训练产物，并独立重放失败端点的目标、梯度和局部数值几何。不重新拟合、不更新参数、不读取 H/query 流量或标签、不修改原停止记录，也不启动恢复。

## 1. 结论

本次恢复流程完成 R0 恢复合同及 R1 兼容端点核验，在 P3 补全训练时停止。直接原因是：

> `main/f1/trojan/G0/outer` 的 `RawPre__m025__UPR`，即 RawPre-U50 必要参照，在统一的 4000 次迭代上限处仍未满足原坐标梯度门。

这不是累计 8 小时活动预算耗尽，不是函数评价次数耗尽，不是 CUDA 内存不足或 NaN，也没有证据表明是网络中断。程序留下正常的失败快照和结项账本，清除了运行锁；没有自动重试。

NR1 先导原有 42 个固定问题均通过的结论不变，但该先导以 f0 为范围，不能保证所有其他折的 RawPre 问题也在 4000 次以内合格。此次失败来自 **f1、Trojan、U50**；它不是原先 **f0、VLESS、U100** 失败端点的重复。

## 2. 当前实验在检验什么

本轮仍是 RA1 角色非对称训练材料替换实验，而不是新增网络或 GAN：

- 四个 TCP 部署、六类业务、五个全局内容外折、三个 C/U 遮蔽组，共 60 个角色。
- 使用既有 96 维访问摘要，分类对象为访问，不是把每个 flow 当成独立标签样本。
- 固定既有 P/G 映射、尺度和分类正则选择；仅比较 C/U 槽位不同的替换比例与来源。
- 主候选是 P-U50，即 `P__m025__UPR`；保留 P-small、同质量对称替换、G-U50、RawPre-U50、RawPost-U50 和 S 等预定比较对象。
- 新拟合统一使用 CUDA float64、原 Cholesky 预条件化 LBFGS、4000 次迭代及 20000 次函数评价；目标、权限和原梯度验收门均不变。

RawPre-U50 是排除“只要补充入口视图就有效”的直接参照，不能因其难求解就删去，再以剩余模型宣布实验通过。

## 4. 独立重放与原因定位

### 4.1 原目标、质量与梯度一致

从封存失败参数和数值槽位直接在 CUDA float64 重算：

\[
J(W,b)=\sum_i w_i\,CE(Wx_i+b,y_i)+0.0025\|W\|_F^2.
\]

结果为：

- 目标：0.2663096576604052，与失败记录差为 0。
- 最大梯度：1.107553351209576 × 10^-5，与记录差约 4.34 × 10^-19。
- 样本质量总和：1；每类质量为 1/6，误差仅为 float64 舍入级别。
- bias 最大梯度约 7.59 × 10^-8，未通过的最大梯度不是共同 bias 平移自由度造成的。
- 输入槽位 SHA256 与失败记录一致；分析前后所绑定的原文件哈希不变。

因此，当前停止不是日志抄错、质量额外除以计算行数、或原坐标重放不一致造成的。这里没有执行任何 Newton 校正或参数更新。

### 4.2 线搜索没有报告失败，但不能据此认定已经充分优化

4000 次线搜索全部记录为满足 Wolfe 条件；Armijo 和曲率条件失败计数均为 0。没有非下降方向或连续参数完全不变的停止记录。

最后 8 次步长近似在 0.350 与 0.177 之间交替；最后一次目标下降约 1.88 × 10^-12。它说明末段推进已很小，但不能仅凭步长交替就断言参数进入精确循环，也不能将“目标变化小”替代原梯度门。

### 4.3 当前局部几何仍然不轻松

本次仅计算终态 Hessian，不求解新模型。使用五维类别对比坐标，排除共同类别分量后：

| 描述量 | 本次终态 |
| --- | --- |
| 最大绝对训练坐标 | 187.0374 |
| 原坐标对比 Hessian 最小／最大特征值 | 0.0029156 / 116.4672 |
| 原坐标对比 Hessian 条件数 | 约 39,946 |
| 现有预条件变换后的最小／最大特征值 | 0.000017028 / 1.325955 |
| 变换后条件数 | 约 77,869 |
| Cholesky 重构最大误差 | 1.14 × 10^-13 |

这与“高尺度 RawPre 坐标下，现有求解轨迹在某些角色收尾较慢”的解释相容。当前固定预条件器不保证改善每个终态的局部条件数；这里也没有看到 Cholesky 分解错误。

但是，条件数与步长序列并不足以证明唯一根因，更不能预测“再加多少次必定通过”。不能将它们包装成对某个替代后端已经完成验证的证据。

## 7. 对研究结论意味着什么

可以确认：

1. 原失败端点的数值预算修订确实在 NR1 先导中解决了原问题，兼容产物核验和完整流程恢复也已执行。
2. 4000/20000 的统一政策对当前全角色范围仍不足以保证数值验收：新角色中出现了另一个必要参照失败。
3. 大多数本次新问题较快合格，困难主要集中于 RawPre，但这不是删除 RawPre 的依据。

不能确认：

- P-U50 是否超过 P-small、G-U50、RawPre-U50、RawPost-U50 或 S。
- 新的 C 业务代价、F1、CE、Brier、显著性或六类混淆矩阵。
- RA1 科学假设已经失败，或者只要修好数值就一定产生业务增益。

当前正确状态是 **业务检验未完成**，不是分类负结果。不能混用旧研究的业务分数给本轮填表，也不应挑出已完成的 f0 或部分角色先评价。
