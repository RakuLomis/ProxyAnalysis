# 0916固定源决策配对校准：完整实验报告

日期：2026-09-20。状态：Q0–Q11完成；未启动flow、R4冻结读出或其他新方法。

## 1. 结论摘要

本轮改变校准目标、不增加映射容量，确实改善了固定源分类器的业务迁移，但**没有在主设置下检出真实配对相对同机制错配的总体优势**。

预先指定的λ=1下：

- 真配决策校准F的macro-F1从旧真配Ridge C的0.768683升至0.853494，增益0.084810，内容簇95%区间[0.055233,0.119480]。
- CE从0.926380降至0.654916 bits，损失改善0.271465，区间[0.216690,0.334937]。
- 同机制错配G的F1为0.865603、CE为0.655022。F−G的F1增益为−0.012110，区间[−0.037879,0.016685]；CE改善约0.000106，区间[−0.066771,0.058835]。
- 新真配修复C的23条错误，同时新增3条错误，净多正确20/240访问。
- 留出中心化logit MSE从3.732687降至2.439953，但统计重构MSE从0.219979升至0.373656，物理范围违反明显增加。

因此，本轮支持“**恢复目标确实影响固定容量下的业务迁移，源决策相关目标可以改善迁移**”，不支持“新增收益已被证明依赖精确同次配对”。未检出差异也不是等效性证明，更不能外推为所有配对学习都无价值。

## 3. 模型、坐标和目标

### 3.1 保持不变的模型

复用五折Full源多类逻辑回归h−及出口逻辑回归h+，复用旧真/错配Ridge。源模型原配置：lbfgs、L2、C=1、max_iter=10000、tol=1e−8、无class_weight。

新映射仍逐维仿射，每折149个斜率、149个截距，共298自由参数。第j个输出只读取第j个post坐标，不是跨维线性回归、MLP或新业务分类头。决策项耦合优化参数，但不增加映射函数的输入依赖或参数数目。

CPU、float64、单线程、Pytorch312。没有新神经训练或CUDA需求，也没有重新训练源/出口分类器。

### 3.2 精确保存原Ridge恢复目标

v为训练post预处理T+的坐标；t为旧pre目标归一化U−的坐标；q=a⊙v+b为映射输出。将其显式转入源分类器T−坐标：

```text
z_hat_j = c_j q_j + d_j
c_j = scale_U,j / scale_T−,j
d_j = (mean_U,j − mean_T−,j) / scale_T−,j
```

恢复损失为：

```text
L_rec = [Σij m_ij (a_j v_ij+b_j−t_ij)² + αΣj a_j²] / (n d)
α=1，n=192，d=149
```

惩罚旧目标坐标中的斜率a，截距不惩罚。共同除以nd不改变旧Ridge最优解及其SSE/正则比例。没有更改为“平均误差加未缩放alpha”，也没有直接惩罚变换后的c⊙a。

五折有效149维的192条训练目标均完整，缺失数为0；错配置换后仍完整。实现对有效目标缺失直接报错，不用填补值伪装监督。源无效维固定为0。

### 3.3 固定源决策项

源分类器logits为Wz+β，P6=I−11ᵀ/6。使用：

```text
L_dec = Σi ||P6 W (z_hat_i−z_i)||² / (n·5)
L_total = L_rec + λ L_dec
```

β在分数差中抵消，但最终推理仍使用完整源截距。去除共同分数偏移后约束的是类别相对分数；该子空间至多秩5，不是完整特征恢复。λ的单位与恢复维数149、类别对比数5的归一化绑定。

真配使用同次pre；错配对t及其源坐标/分数统一使用旧同部署、同内容重复循环1→2→4→5→1。没有把错配恢复目标与真实决策目标混用。该错配保留内容、部署及业务结构，不是任意不同业务或独立重采样。

固定λ={0,0.1,1,10}，λ=1在看结果前确定为主设置；0.1、10只作敏感性。没有内层搜索，也没有根据外层测试性能重命名最佳设置。

### 3.4 数值求解与复现门

通过小型正定线性系统求解凸二次目标，不做显式矩阵求逆、不加jitter或额外正则。独立审计用显式增广残差设计和QR最小二乘，未共享主求解器的二次型装配函数。

λ=0的10次求解先全部通过C/D复现，才运行30次正λ：最大参数差3.11e−15，源坐标/logits/概率最大差3.60e−14，分类完全一致。正λ系统条件数范围24.99–2561.00，最大归一化梯度残差2.44e−17。

## 13. 对论文主张和下一步的约束

本轮最合理的表述是：

> 在固定逐维仿射校准容量与固定源业务分类器下，加入源相对决策分数保持目标可改善留出内容上的post业务迁移。该收益伴随统计恢复与物理合法性的代价；在同内容跨重复错配控制下，主设置未显示精确同次对应的总体分类优势。

上一轮C优于D的结果没有被撤销，而是其优势对恢复目标具有依赖。本轮说明业务决策目标能让保留内容/业务结构的错配获得很大改善；这不足以确定收益全部来自业务均值、内容均值还是某种正则化，未开展新的层级或因果识别实验。

这两个命题应分开：一是精确配对有助于原统计恢复目标下的迁移；二是任务感知目标下，精确配对仍否提供额外业务收益。当前第一项有旧对照支持，第二项的合并主设置未获得支持。

pre业务标签可通过已有真配关系转给post训练E，因此不声称已节省人工标注成本。也不证明变换可逆、业务语义解耦、无配对部署或未见协议泛化。0916已被反复分析，区间条件于已有模型、未校正多重比较，缺少新数据外部验证。

按计划在此交付并停止，不自动搜索更多λ、加大模型、强制物理投影、转flow或启动R4支线。若继续，需要用户选择下一科学问题：解释任务感知收益的对应关系层级，还是检验在保持业务收益时能否减少适配向量的物理失真；两者应另立受控方案，不混为本轮补丁。
