# Author decisions before submission

- Target journal and manuscript category; corresponding page limit and anonymity rules.
- Author names/order/affiliations, contact information, funding and acknowledgments.
- Publishable deployment inventory: implementation versions, transport/security options, host and client specifications, collection durations. Existing source artifacts should be verified before adding a definitive system-setup table.
- Collection authorization, any institutional review requirements, and publishable ethics wording.
- Data/code availability and sanitization policy. No public trace release was performed.
- Focused novelty review against recent proxy traffic analysis literature. Eight verified foundational references do not establish exhaustive novelty.
- Broader claims still require external deployment/date/network validation; not performed for this draft.

These are visible limitations of a reference draft, not invented facts or hidden completed tasks.
