# 漂移感知业务分类模型说明

用途：已知当前部署及父访问范围时，利用合格post连接识别六类domain × activity。

训练业务模型S带标签；无业务条件的M1/M2从同折训练两侧估计。Q=S K，精确求和而非采样或逆变换。十核不构成联合似然，平均log评分softmax只是可评价的复合概率输出，不保证校准。

推理数值输入仅96维post连接箱频率，无测试pre、标签、content ID、SNI、IP或端口。每部署独立路由，相同权限给post基线。没有连接数或时间特征。

限制：共享核近似可能不成立，源业务差异可能被粗箱和核抹平；类内内容支持有限。当前离线共同资格及访问索引不能自动在post在线重建。未验证未知部署、跨日期、DIRECT、AnyTLS或Hy2。分类解释为分数贡献，不是协议因果解释。
