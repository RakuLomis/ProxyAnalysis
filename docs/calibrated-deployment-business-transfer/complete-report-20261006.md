# 辅助业务校准与跨部署业务迁移实验完整阶段总结

日期：2026年10月6日。状态：三次运行均为工程中止，主校准迁移实验尚未完成。

本总结覆盖本轮从原始研究问题、数据资格、表示与概率核、训练权限、分类对照、已完成迁移诊断，到两次修复及第三版先导中止的全过程。它不是整个ProxyAnalysis历史实验的总报告，也不把此前0914、0916、记录序列或六协议增广的结果拼接成本轮新成绩。

最重要的结论是：**已经测清当前96维表示的跨部署分类与核迁移关系，但尚未完成“目标只有辅助业务校准时，精确配对核能否提高另外两类业务识别”的主检验。** 当前没有CT4对StrongPost、CT1或CT3的主测试差值与显著性结果。三次中止都发生在数值求解阶段，不能解释为配对方法的业务负结果。

## 一 研究问题为什么改变

此前部分跨业务增广实验允许目标未覆盖业务提供pre。那些实验可以检验合成训练数据的用途，但不足以回答更严格的部署迁移问题：攻击者若只有其他部署的业务库，能否在目标部署只采集少量辅助业务后迁移到没有目标训练观测的业务？

本轮固定问题为：攻击者已有三个源代理部署的完整六类业务库，在第四个目标部署只能使用四类辅助业务的pre/post及标签进行校准。目标另外两类业务的训练pre和post均不得用于缩放、核拟合、生成、查询、分类训练或选参。测试仅输入目标post数值。

因此，本轮不是未知类别识别：六类在源库中都已知；缺失的是两类在目标部署中的训练观测。它也不是完全无目标数据的域泛化，因为目标四类辅助业务提供了真实校准数据。本轮恰当命名是“辅助业务校准条件下的跨部署迁移”。

部署同时包含协议、节点、配置、软件实现和网络路径。没有独立改变这些因素，不能把全部差异直接解释为某个协议的纯算法效应。目标部署身份允许用于校准核路由和角色组织，但不作为数值分类特征。

## 四 采集数值如何成为模型输入

### 十项连接统计

| 特征 | 观测定义 |
| --- | --- |
| W_up、W_down | 正TCP载荷观测字节量，包含重复传输 |
| U_up、U_down | 已观测唯一TCP字节量 |
| P_up、P_down | 正载荷包数 |
| E_up、E_down | 带正唯一新字节的到达事件数 |
| FR_packet_runs | 正载荷包方向run数；非空序列为1加方向切换数 |
| R_unique_zero_runs | 唯一新字节到达序列的零阈值方向run数 |

这里的FR保留原非空方向run口径，没有替换成TLS记录时间排序的方向切换。R_unique是另一项观测，不能与FR混名。U是观测到的唯一字节，并不自动表示捕获完整的应用层净业务字节。

本轮没有把IAT、RTT、握手语义、TLS记录类型、initial/relay划分或精确协议开销K加入分类器。这些属于项目其他阶段的观测或未验证边界，不是本轮输入。

### 每访问的96维表示

每个父访问中的合格连接分别统计上述十项值，再对每项构造连接频率直方图。四项字节统计各9箱，六项计数统计各10箱，合计96维。每一块按该访问连接数归一化，块内和为1；访问级分类样本不是单连接样本。

字节边界为1、256、1024、4096、16384、65536、262144、1048576；计数边界为1、2、3、4、8、16、32、64、128。边界值进入右箱，0独立成箱，末箱开放。所有部署、两侧、折和方法共用这些物理边界，不根据测试数据调整。

这保留了访问中的连接统计分布，丢弃了许多更细的顺序和联合关系。它不是完整包序列，也不是把一个真实flow截成多个训练样本。原post直方图重放最大误差为1.1102×10⁻¹⁶。

### 明确排除的强指示信息

IP、端口、SNI、域名文本、协议ID、配置hash、内容ID、访问ID、绝对时钟和资格标志均不进入数值分类器；也不另加flow数量。访问ID只用于结果对齐，内容ID用于整体划分及组控制，部署ID用于角色和核路由。

这里的“post-only”是模型数值接口约束，不等于整个数据整理过程从未使用pre或离线关联。所有方法共享既有离线配对资格集合；这项测量基础的总价值不能由CT4对CT3的差值完全量化。

每外层场景，三源部署中的每一个轮流作伪校准目标，另外两个提供完整业务库；外层训练内容再按4个内容折留出。因此每场景有3乘4等于12个内层角色，共720个内层角色，另60个外层角色，总计780。

一个内层角色使用两个源的18个训练内容、144次源访问，以及伪目标四类的12个内容、48次校准访问。伪目标未覆盖训练区24次访问排除；验证覆盖6内容、24访问。实际外层目标在内层选择中完全不可用。

## 六 漂移核如何构建

### 真配核

对每项特征j，在目标允许的四类C中，将真实连接两侧分箱结果记为a和b，累计联合质量N_j(a,b)。每内容质量为1，每内容四重复各1/4，一次访问内连接等权：

\[
w_{u,r,i}=\frac{1}{4n_{u,r}}.
\]

外层C的总质量为16，内层为12。不能把它再归一为1同时保留原平滑常数，否则核会改变。固定核为：

\[
q_j(b)=\frac{\sum_aN_j(a,b)+1/k_j}{\sum_{a,b}N_j(a,b)+1},\qquad
K_j(b\mid a)=\frac{N_j(a,b)+q_j(b)}{\sum_bN_j(a,b)+1}.
\]

k_j为9或10；每入口行平滑质量为1，训练未见入口箱回退到q。核不以业务标签为数值条件，标签仅用于定义C/U权限和后续分类监督。

### 匿名组核

匿名控制只知道两侧来自同一内容，不知道具体哪个连接或哪个访问互相对应。独立打乱两侧包，删除pair、session、visit、carrier、重复编号及共享行序，按内容得到两侧边际A与B，再构造：

\[
N_j^{group}(a,b)=\sum_u\frac{A_{u,j}(a)B_{u,j}(b)}{m_u},\qquad m_u=1.
\]

使用同一q与平滑尺度。真配与组核两侧边际验收差约5.33×10⁻¹⁵。两者都依赖真实目标C两侧数据；组控制不是无post模型，也不是不使用漂移数据。

两者的比较隔离的是目标校准的连接级耦合相对同内容边际的用途。本轮没有额外源实例对比损失，不能把它解释为源库精确身份的独立贡献。

### 源pre怎样形成辅助训练数据

对源访问的每个入口直方图块h，用目标C核得到：

\[
\widetilde h_{v,j}=h^{source,pre}_{v,j}K^{C}_{target,j}.
\]

输出仍为96维、块内非负且和为1。它是期望箱频率，不是抽样得到的完整TCP会话或PCAP，也不保证跨变量联合合法性、业务标签或决策边界保持。不会使用目标U的pre作生成查询，更不按两部署第几个flow强行对应。

与旧合成合法摘要实验不同，本轮没有建立“段数、事件余量、字节余量”联合生成器；本轮研究的是离散条件核映射访问直方图。

## 七 分类方法与训练契约

### 七个报告对象

| 对象 | 源主槽 | 源辅助槽 | 目标槽 | 解释 |
| --- | --- | --- | --- | --- |
| CT0 PostJoint | 真源post | 同一post重复 | C post | 充分同权限post监督 |
| CT1 RawPre | 真源post | 原样源pre，删除跨侧精确身份 | C post | 更多源侧数据控制 |
| CT2 CORAL | 真源post | matched-C CORAL后的源post | C post | 常规适配参照 |
| CT3 GroupKernel | 真源post | 源pre经目标匿名组核映射 | C post | 粗对应控制 |
| CT4 PairedKernel | 真源post | 源pre经目标真配核映射 | C post | 精确对应主候选 |
| StrongPost | 复用源内选定CT0或CT2 | 与所选臂相同 | C post | 强post主参照，不在目标测试上选优 |
| CT5 TargetFull | 不要求三源槽 | 不要求辅助槽 | 完整六类目标post | 显式更多资源参照 |

CT5复用核验后的历史KSR1目标post模型，仅用于评分参照，不能把参数或目标六类选参结果泄给主臂。StrongPost不新增拟合，只复用CT0或CT2。

本轮没有VICReg、MLP、LLM、教师蒸馏、神经辅助头、正反例对比损失或新风险重加权。精确配对用于概率核计数，而不是加入神经网络的配对训练损失。

### 共享缩放与CORAL

五主臂共用只由合法真实source-post与C-post拟合的均值和总体标准差。外层352个真实行，内层192个真实行；常数维标准差置1。辅助视图、目标U和测试数据不改变缩放器。

CORAL只在四个相同辅助业务上拟合每源的均值和无偏协方差。共同标准化坐标中的变换为：

\[
\widetilde z=(z-m_s)(\Sigma_s+I)^{-1/2}(\Sigma_C+I)^{1/2}+m_C.
\]

对角正则固定为1，CUDA对称特征分解；变换只作用于源辅助槽，源主槽和目标C不变，测试post不再经过CORAL。该辅助槽变体的用途仍须主实验评价。

### 损失质量

六业务各占1/6。未覆盖两类仅来自源库；辅助四类的源平均与C平均各占1/2。源业务库内部按部署、内容和重复等权，主辅槽各占源访问质量的1/2：

\[
J=\frac16\sum_{y\in U}L_{source,y}
+\frac16\sum_{y\in C}\left(\frac12L_{source,y}+\frac12L_{C,y}\right)
+\frac\rho2\|W\|_F^2.
\]

三个总槽位质量各为1/3。外层每臂640个加权视图行，内层336行；独立真实访问仍分别为352和192，重复或变换不会创造更多独立访问。

CT0两个post槽相合等价于加权直接post目标。其他臂替换辅助槽，真实post的曝光质量比CT0少一个槽；准确表述是相同真实post资源、同主槽、同总质量及预算，而不是完全相同的真实post曝光次数。

### 分类器和验收

模型是96输入、6输出的多项逻辑回归，W为6乘96，bias为6，共582参数，无隐藏层。它不是sklearn默认实例，而是CUDA float64的带权CE优化。正则候选t为0、0.25、1、4，rho为0.001乘以1加t，bias不正则化，零初始化。

最初采用本机PyTorch 2.5.1 LBFGS与strong-Wolfe。正式门为目标不增加超过10⁻¹⁰、原坐标最大梯度不超过10⁻⁵、迭代数严格小于500，以及目标和梯度独立公式误差各小于10⁻¹⁰。第二版起显式记录原默认max_eval为625；线搜索可在一轮中产生多次评价，因此它是迭代边界评价停止值，不是任意情况下严格不越过的硬上限。

所有数值核、映射、训练、推理和模型复算使用CUDA float64，无CPU求解回退。CPU用于文件、统计汇总和绘图。小型独立LR的GPU利用率不保证饱和；不能以利用率较低推断没有使用CUDA，也不应为此改变模型容量。

## 十 原本要怎样判定主实验

完整主矩阵需要14400个内层候选与300个外层模型。最初总新拟合预算为阶段一680加主14700，合计15380，不包含单元或明确工程复现；后续版本的重跑另列。

每外层场景在12个源内角色中选择五臂各自t，并从CT0、CT2选StrongPost。平分容差10⁻¹²，t优先较小；StrongPost同分优先CT0。所有选择必须先封存，才拟合外层；所有主预测先封存，才开放评分与测试pre。

最终应有10080行七对象预测：60场景乘24测试访问乘7对象。真实访问仍为480，三个业务掩码和多个方法重复使用同一访问，不能把10080行当独立样本。

每目标每组先合并五折120条预测，计算完整6乘6混淆矩阵，再取未覆盖两类F1均值。其他四类导致的假阳性仍进入分母，不能简化为只在两类子集上测试。

主要比较固定为CT4减StrongPost、CT4减CT1、CT4减CT3。采用10000次按业务分层内容bootstrap，seed为20261005，所有部署、重复、方法和业务组共用同一30内容权重。三项组成同一检验家族，98.3333%校正区间下界均大于0才称三项增量同时成立；95%区间仅并列描述。

辅助业务代价筛查为CT4相对三主参照的合并F1_aux点差不低于负0.02，且相对StrongPost的最差目标差不低于负0.05。它不是统计非劣效，也不能因区间跨0就称等效。

所有bootstrap条件于固定选定模型，不重训内外层，不表示完整训练不确定性或外部盲测。当前上述主差值、区间、安全筛查与错误翻转尚未产生。

### 第二版 原目标等价预条件化

保留原科学契约，新增逐项日志与失败状态，再构造：

\[
A=[X,1],\quad H_0=\frac16A^T\operatorname{diag}(m)A
+\rho\operatorname{diag}(1,\ldots,1,0)=LL^T.
\]

优化V，令Theta等于VL的逆、变换输入等于AL逆转置。变换目标仍惩罚映回的W，不惩罚V或bias。最终在原X上重新计算原梯度，不能用V梯度验收。

## 十三 数据隔离和复现性证据

输入、源码、计划、契约和数值修订分别封存，原科学定义与工程I/O改动区分。可信打包器可见完整台账，但拟合和推理进程只能读取用途白名单包，不能用完整主表代替权限包。匿名组包无精确连接身份，原样pre控制的排序与标签和损失质量独立对应。

评分标签和离线测试pre是分离包，必须在全部主预测封存后才能读取。三版都未产生主预测或封存选择，因此没有执行主外层评分。阶段一诊断自己的预测与评分封存单独管理，其目标pre只用于阶段一离线核测量。

第一版诊断分数从4320条已封存概率重算，与保存的36个单元成绩最大误差为0；旧post对角概率重放误差约1.33×10⁻¹⁵。第二版104个、第三版24个合格候选的原目标和梯度均经过独立CUDA复核。

停止后审核过原13个、第二版8个、第三版8个源码；第三版审核953项历史依赖、5960角色包、15493项引用登记和29项旧状态与报告快照hash。清单重叠，不能相加称不同文件总数。本次总结再次校验29个封存源码，基于已保存评分生成独立数值附录，没有训练、重新推理或读取新的测试包。

这些证据支持当前登记队列的成员隔离、输入权限和数值可追溯性，不证明全部历史连接epoch问题消失，更不替代新节点、新日期或全新配置的外部验证。30内容和这些部署在历史研究中已反复分析，本轮预登记不使它们变为研究者未接触的盲测。

## 十四 哪些结论可以保留

可以保留四项具体成果。第一，当前入口连接直方图具有较稳定的跨部署业务可读性。第二，出口分类迁移和源概率核迁移有明显方向差异，多源post共享不能覆盖所有目标。第三，条件对数评分收益与分类边界复用不等价，概率关系的业务用途需要独立对照。第四，两个原目标等价的工程修复已形成可审计实现及失败状态，把最初笼统质量门错误推进到具体迭代、梯度和评价预算证据。

不能写成成果的包括：精确配对校准已提高未覆盖业务识别，已经优于组控制或强post基线，三项主比较已通过或未通过，已验证节省目标采集成本，已完成六协议通用模型，以及仅凭现场post完成无索引在线识别。

当前停止不否定TrafficTracer的测量和关联价值，也不证明当前概率核适合或不适合分类。它仅说明固定求解方案尚未完成原业务假设的公平主检验。

## 十五 下一步前真正需要决定的事项

原任务、标签、配对和组控制、源库权限与主统计终点仍可继续保留。当前问题不是再选更容易的业务、更多生成视图、另一种辅助损失或更大分类头。

若继续，需另行登记五主臂统一的数值预算或求解器修订，保持原凸目标与验收。小变化早停已修复，继续只调该阈值不能解决已记录的625评价停止。单独增加max_eval是否足够还未知，因为500次迭代也可能成为下一约束；任何新上限或新求解器都需要有限验证，不能先承诺全矩阵一定完成。

三个旧运行及其报告全部保留，不warm-start失败状态，不静默追加step，不只给CT1更大预算，不把第二版合格模型混入新的统一主表。当前并未启动下一修订。
