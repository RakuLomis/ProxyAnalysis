# P7 线性配对约束：完整实验结果与MLP对照解释

日期：2026-09-18。状态：320次正式拟合、独立审核、完整统计与图表已完成。

## 1. 结论先行

P7没有将MLP的局部成功复制为普遍的线性约束收益。在固定scalar14、240队列、三种λ和双向部署条件下，没有任何设置同时获得G_task、G_pair、G_reg的95%条件区间全部为正。

真实配对在部分设置下明显优于错配和等trace各向同性正则，但仍未稳定超越不加约束的新R0。因而“对应关系影响约束质量”与“增加该约束有净收益”仍是不同结论。

这不否定MLP结果，也不能证明所有配对约束无效。MLP实验改变学生模型与学习程序，使用既有教师软目标；本P7是固定线性分类器上的方向正则，两者不是同一种方法。MLP最明确的局部正例还使用distribution157，而P7只使用scalar14，不能当作纯粹损失函数优劣的因果比较。

## 3. 目标与数值口径

令d_i=φ(post_i)−φ(pre_i)，保留未中心化二阶矩CΔ=mean(d_i d_i^T)。对非零矩阵使用Cbar=CΔ/(trace(CΔ)/14)，使trace=14；零矩阵保持零，不用任意ε造出约束。

多类损失为平均硬标签CE(nats)＋λ tr(PWCbarWᵀP)＋||W||²/(2nC)，P去掉类别logit共同平移，C=1。截距不受惩罚。

二类使用单log-odds v，配对惩罚为vᵀCbar v/2，基础L2为||v||²/(2nC)，与已审核的sklearn二类目标尺度一致。

R0使用λ=0；R-Iso以I替代Cbar。相同trace并不意味着相同有效自由度、训练误差或实际权重下的惩罚强度。每个真/错配矩阵各自归一化，因此检验更侧重方向几何，而非原始变换总量。

优化器为双精度SciPy L-BFGS-B，gtol=1e−10、ftol=1e−15、maxiter=10000。320个模型均success且梯度无穷范数≤1e−6，没有因表现不佳而重跑或调参。

## 6. 机制诊断：源侧恒定特征使配对矩阵高度集中

YouTube、SS源部署的五个训练折中，post的length_median均值为1428，方差为零，StandardScaler按其规则使用scale=1，而不是除以零。pre侧该统计量并不相同。

因此真实配对原始二阶矩trace约202万–231万，归一化后length_median的对角值约13.9994–13.9996，占总trace超过99.995%。这不是发现标准化程序出错，而是共同源post坐标与全矩阵trace归一化的一个实际结果。

该维度在源训练post标准化后恒为0，R0不能利用它区分训练样本；真实配对约束通过维度耦合仍可能改变该维权重，而目标部署取值未必恒为0。因此，同部署预测变化很小，不保证跨部署也不变。该现象与本次“SS同部署几乎不变、迁移CE发生变化”相符；不能据此将全部误差归因于单维。

本轮没有据此删除该特征、单独标准化pre或更改归一化。任何这样的尝试都是新的表示/约束实验，不属于原冻结结果。

## 7. 与MLP实验合并后的判断

MLP的YouTube、distribution157、SS→VLESS局部正例仍成立：M2平均F1=0.5811，M0=0.3440，并优于错配和普通软监督。但该模型不是当前scalar14线性P7。

现在可以区分三个层次：

1. P5/P6提供可解释的计数变化和冻结模型敏感性证据。
2. 固定线性教师的软监督，能被某些MLP设置转化为局部单侧分类收益。
3. 直接惩罚线性分类器的全局配对变化方向，并未在本固定实验中形成稳健三重净收益；约束质量还受共同坐标和矩阵集中度影响。

下一步不应自动扩大λ搜索。建议先决定是核验MLP局部正例的队列/教师分法稳定性，还是开展一个明确修改矩阵尺度的机制实验；非线性P7同样需要单独冻结损失尺度和普通正则对照。本轮已到既定终点，这些扩展均未启动。
