# 流级条件概率模型说明

## 用途

描述固定Extend配置下的真实连接对应与内容外统计预测。部署c已知，用于选择条件核。输入是pre统计箱，输出是对应post单变量分布；不是业务分类器、完整信道模型或合法会话生成器。

## 输入与权限

主模型每次只查询一个入口统计，负载补充最多加一个pre唯一总字节层。地址、端口、SNI、URL、业务标签、endpoint及凭据不作为数值输入。内容ID仅用于训练匿名组控制及统计。测试pre允许；测试post只能用于评分。

## 实现

真实联合加权频数与同内容匿名组乘积控制，固定物理分箱，alpha=beta=1的边际回退平滑。全部拟合与推理使用Pytorch312的CUDA float64。原单位伴随分布给中位数及80%/90%区间。

## 已检验范围

四已见部署、23566排他TCP连接、30内容、四重复、五折全局内容留出；另有AnyTLS在内的五部署600访问窗口补充。登记carrier/logical不跨折；未宣称完整TCP epoch重建或任意未观测连接的普遍证明。

## 限制

逐列概率不是十维联合生成分布，各列独立采样不保证摘要合法。主分箱可能隐藏细粒度变化；窗口出现单箱退化。平滑可在经验MI=0时改变预测损失，所以log-loss增益不等于MI。信息估计和bootstrap仍有有限样本/回顾性边界。

M2没有可靠同角色控制，不能将真配增量全归为访问级残差。没有业务分类、纯协议因果、精确K、语义阶段、外部DIRECT或未见部署验证。AnyTLS逻辑stream和Hy2载体不获得排他TCP资格。
