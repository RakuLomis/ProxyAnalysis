## 6. 模型与完整损失


该标识含GAN，但实现**不是完整GAN**：没有可训练判别器、随机噪声或极小极大更新。准确名称是“配对锚定逆向摘要校准＋有限条件矩＋概率融合”。

每块冻结逆Ridge G0：输入z_B=S_B(b)，目标raw pre a（P）或匿名组pre中心（G），α=1，截距无正则。十块共1020个估计参数。动态残差为r(z)=U2 ReLU(U1 z+d1)，96→8→96，无输出bias，共1544参数；U1随机、d1=0、U2=0，初始输出等于锚点投影。

\[\widehat a=\Pi_{\mathcal H}(G_0(b)+r(S_B(b))),\qquad h_A(\widehat a)=W_A S_A(\widehat a)+c_A.\]

Π_H为逐块欧氏单纯形投影，不是softmax或截断归一化；只保证块内非负且和1，不保证合法协议会话、整数直方图、跨块一致性或业务保持。

\[J=\tfrac12 CE_w(h_A(\widehat a),y)+\tfrac12 CE_w(h_A(a),y)+L_{rec}+L_{fid}+L_{gap}+0.1L_{dev}+\gamma(\|U_1\|^2+\|U_2\|^2+\|W_A\|^2).\]

rec为raw平方误差/10；dev为未投影残差平方/10。fid使用部署×业务的一阶与原始二阶矩，尺度分别1/10、1/100；gap只约束C业务生成误差的目标—源域差，不强迫真实pre域差为零。固定有限核为k(a,c)=aᵀc/10+(aᵀc)²/100，不能据前两阶矩宣称完整分布匹配。

| 臂 | 定义 | 用途 |
| --- | --- | --- |
| B0 | 原P-small | 全程冻结，无新分支 |
| R-P | 真配逆Ridge＋凸头 | 无动态残差/矩 |
| R-G | 组中心逆Ridge＋凸头 | 无逐访问对应 |
| N-P | 真配动态恢复 | 删除fid/gap，其余与F-P相同 |
| F-P | 真配动态恢复＋fid/gap | 主方法分支 |
| F-G | 组中心恢复＋真实边际fid/gap | 匿名组控制，矩不是中心外积 |
| E-post | post→post残差＋任务与dev | 无任何pre监督，无逆锚点 |


动态部分名义可训练2126参数（Q对比坐标自由参数2029）；逆向方法另有1020个冻结估计锚点参数。E-post的可训练部分同量级，但不含逆锚点，不能声称总估计复杂度完全相等。

## 19. 本轮究竟支持什么、不能支持什么


| 层级 | 命题 | 证据或边界 |
| --- | --- | --- |
| 支持 | 当前真配逆锚点/恢复组合比匿名组组合更好 | 五项主比较之一99%区间为正，主要由SS贡献 |
| 支持 | 当前完整F-P-FUSE整体不如P-small | 主区间为负，四部署U点估计均低 |
| 支持 | 晚期融合明显减轻纯分支损害 | 描述性FUSE/PURE表；二者分别选择，不是同一模型单因素因果实验 |

| 不支持 | 动态分支稳定优于静态真配逆Ridge | F-P−R-P区间跨零 |
| 不支持 | 引入完整GAN后效果仍负 | 本轮根本没有判别器或对抗训练 |
| 不支持 | 所有配对学习或所有漂移信息都无效 | 只裁决当前表示、映射、目标、队列与训练政策 |
| 不支持 | 真实pre恢复成功/失败已在H验证 | 没有H-pre读取，只有训练恢复诊断 |
