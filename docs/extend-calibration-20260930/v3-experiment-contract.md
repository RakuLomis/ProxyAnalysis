# Extend v3 实验契约说明书

本文面向论文读者与复核者，说明已完成的 Extend v3 校准增广实验。它是事后证据整理，不是新的事前预注册。冻结预算、权限与判据来自准备合同和两版执行合同；历史报告中的“未授权训练”“尚未运行”是当时状态，不是当前状态。

实验已经完成：W 五部署、T 四部署全部通过预定 paired−raw 和 paired−group 双增量判据。该结论不等于条件生成器普遍最优，也不等于真实流量生成、跨部署泛化或外部验证。

配套文档：[数据与观测](v3-cohort-and-observation.md)、[连接与字节保留表](v3-coverage-tables.md)、[完整补充结果](v3-results-supplement.md)、[复现指南](v3-reproduction-guide.md)、[证据索引](v3-evidence-index.md)。原 [正式结果表](formal-v3-results.md) 不被覆盖。

## 研究对象与终点

问题是：在已见部署内，只用少量内容的真实 pre/post 校准，能否为额外只有 pre 和既有业务标签的内容生成有用摘要，从而改善真实留出 post 的六业务识别？比较的是部署内内容泛化，不是用 SS 拟合后到 VLESS 测试。

六业务为 GitHub 仓库浏览、YouTube 搜索、Bing 搜索、Wikipedia 文章、MDN 文档和 YouTube 视频播放。每业务五个固定内容，每内容四次访问。分类器最终只接收 W 六维或 T 七维数值；IP、端口、SNI、域名、协议名、内容 ID、会话 ID 和质量标记不作为数值输入。它们可用于标签、关联、分组与审计，不能因此说整个研究从未使用元数据。

F1_new 从完整六类混淆矩阵取本场景两个新增业务的 F1 均值。来自其他四类的误报仍影响新增业务 precision，不是二分类或只在新业务样本上重算的混淆矩阵。

## 内容划分与可用资源

同内容的四次重复、父访问、双侧及内部连接整体随内容划分。五折中每业务留出一个内容，H 共六内容 24 访问；训练区每业务四内容，共 24 内容 96 访问。没有内部超参数搜索或额外验证集，不应虚构训练验证测试三套划分。

| 新增业务组 | 不向生成器提供真实 post 的目标业务 | C 可来自的其余业务 |
|---|---|---|
| G0 | GitHub 仓库浏览、YouTube 搜索 | Bing、Wikipedia、MDN、YouTube 播放 |
| G1 | Bing 搜索、Wikipedia 文章 | GitHub、YouTube 搜索、MDN、YouTube 播放 |
| G2 | MDN 文档、YouTube 播放 | GitHub、YouTube 搜索、Bing、Wikipedia |

C 从四个非新增业务中选六内容，分配为两个业务各两内容、另外两个各一内容，合计 24 访问。U 为剩余 18 内容 72 访问，其中新增业务八内容 32 访问，其余业务十内容 40 访问。U 不是纯新增业务集合。H 包含六类，共 24 访问。

八个 C 轮换沿用历史角色模板，而非按本批结果挑选。原规则 rotation=2t+s，t=0…3、s=0…1；按登记 salt 排序内容及业务，对第 j 个非新增业务选择 m=2（(j+t)%4<2）或 m=1 个内容，位置为 (t+2s+z)%4。具体成员以冻结 roles.parquet 为准，Extend 将旧内容角色映射到新访问和重复 1–4，没有使用旧模型预测。不能把已有角色模板包装成独立外部验证。

每部署每轨道有五折 × 三业务组 × 八轮换 = 120 场景。W 600 场景、T 480 场景，共 1080。各臂训练分类器使用相同 C_post+U 表示和相同 96 个标签；差别是 U 的表示及生成器的对应权限。

## 数据权限矩阵

| 臂 | C 对应信息 | U 分类输入 | U 标签 | U 真实 post | H pre |
|---|---|---|---|---|---|
| raw | 不拟合生成映射；共同缩放使用 C_pre | 原样 U_pre | 使用 | 禁止 | 禁止 |
| center | 真实访问配对的漂移 | pre 加中心漂移后解码 | 使用 | 禁止 | 禁止 |
| marginal | 真实访问配对的完整漂移向量池 | pre 加抽到的漂移后解码 | 使用 | 禁止 | 禁止 |
| paired | 同次访问精确 pre/post | 条件中心加真实配对残差后解码 | 使用 | 禁止 | 禁止 |
| cyclic | 同内容内跨重复循环 donor | 错配目标拟合及残差生成 | 使用 | 禁止 | 禁止 |
| group | 同内容成员集合，无访问配对 ID | 内容中心目标及 Cartesian 残差生成 | 使用 | 禁止 | 禁止 |
| reference | 不依赖生成；共同缩放仍使用 C_pre | 真实 U_post | 使用 | 受限预测封存后开放 | 禁止 |

所有分类器都在 C_post 上使用真实标签。group 的生成 worker 不读 labels，G_post 没有 session_id、repetition 或 T 的 post F；分类 worker 仍获得训练标签。组内按数值坐标规范排序，不能用共享原始行顺序恢复对应。

H_post 仅用于冻结模型推理；H_labels 在两种权限模式的预测封存后进入评分。隔离是代码白名单、分包、哈希与阶段检查，不是操作系统级安全沙箱。既有数据资格和共同 pair 选择曾使用双侧证据：这是模拟学习权限的历史离线实验，不能声称 U_post 在现实采集和样本资格阶段完全不需要。

## 生成方法

这里生成的是必要约束下的摘要，不是 PCAP、TLS 记录或可重放的协议会话。所有生成臂最后还原为相同分类坐标，不向分类器新增 latent、donor 或审计信息。

T 使用 a=(U_up,U_down,E_up,E_down,R_up,R_down)，以及固定查询 pre F。定义 N=R_up+R_down、D=R_up−R_down、G=E−R、H=U−E，编码为：

`[log(N+0.5), asinh(D), log(G_up+0.5), log(G_down+0.5), log(H_up+0.5), log(H_down+0.5)]`。

解码先 floor(exp) 得非负整数，N 至少为 F；D 在 |D|≤F 且与 N 同奇偶的格点上取值。R=(N±D)/2，E=R+G，U=E+H；R=0 的方向同步将 E/U 置零。溢出即失败，不重抽样、不隐式兜底。T 生成样本保留查询 pre F，不复制 donor post F。

W 使用 a=(W_up,W_down,P_up,P_down,R_up,R_down)，L=65527，G=P−R、H=W−P、M=(L−1)P，编码为：

`[log(N−0.5), asinh(D), log(G_up+0.5), log(G_down+0.5), log((H_up+0.5)/(M_up−H_up+0.5)), log((H_down+0.5)/(M_down−H_down+0.5))]`。

W 解码保证全局 N≥1、|D|≤1、奇偶一致，P≥R，P≤W≤LP，并联动零方向。字节余量由有界 sigmoid 参数化得到，不把无约束 log 残差直接当作合法字节数。

paired/cyclic/group 均使用固定 alpha=1 的多输出 Ridge，训练均方目标按样本数归一，截距不正则化。输入为 C_pre 的 log1p 坐标，按训练均值/总体标准差缩放；预测目标是相对于编码 pre 的 latent 漂移，再按 C_pre latent 总体标准差缩放，近常数维度的尺度置一。拟合使用 CUDA float64。

paired 的目标为精确 post latent；cyclic 在同内容重复 1→2→3→4→1 循环替换 post；group 对每个 pre 使用同内容 post latent 均值。每种条件模型拟合一次全 C 模型和六次留一内容模型，后者形成 OOF 残差池。paired/cyclic 各 24 行；group 每内容四 pre × 四 post，共 96 行 Cartesian 残差。group 的目标均值等价于组内平方损失平均，但不等价于循环单 donor。

center 使用真实 latent 漂移的逐维中位数；marginal 抽完整漂移向量而不是逐维独立抽取。二者都需要 C 的真实对应。不能用它们的高分论证“配对无用”；它们检验的是当前条件中心和残差建模是否比简单配对漂移额外有用。

W 使用每 seed 的固定 RNG，24 行残差/漂移池直接均匀抽样，group 在 96 行中抽样。T 使用 seed、scenario、query session_id、view 哈希作为种子，先选内容再选 donor；非 marginal 臂按训练 pre 空间距离排序六个内容后仍在全部六个中均匀选择，不是只取最近 k 个。group 在选中内容独立选择四个 pre 与四个 post。两轨保持原算法，不宣称采样完全相同。

每 U 访问生成八视图，每臂每 seed 有 72×8 个样本；五个生成臂、三个 seed、1080 场景共 9,331,200 条视图。方向限制与零方向联动属于预定义解码支持域，不是事后修补成功率。零非法率不能证明分布真实、标签保持或机制正确。

## 分类器与相同预算

输入为 log1p 原始 W 六维或 T 七维，只按该场景 C_pre 的均值/总体标准差缩放，近常数尺度置一；不使用 U_post/H_post 估计尺度。网络为 6或7 → 32 ReLU → 6，CUDA float32、Adam lr=0.001、1000 步、batch=24，损失为 CE 加 0.5×10^-4×两层权重平方和，不正则化 bias。三个 seed 为 20260918、20260919、20260920。无早停或测试选模。

每步选每业务一个训练内容的四重复，共六类 24 访问。四个训练内容轮换，1000 步使每访问曝光 250 次。C_post 和 raw/reference 的 U 视图在八槽中重复；生成臂按同一随机视图日程抽八视图。八视图没有带来八倍更新预算。各臂每 seed 同初始化、同访问与视图日程；18 头批处理只是计算并行，不共享参数或梯度。

受限模型数 1080×6×3=19,440；reference 1080×3=3,240。生成器拟合、工程冒烟和数值重放不计入此数。正式训练与推理均 CUDA；文档汇总和统计可使用 CPU。

## 统计契约

先在每个 track/protocol/business_group/rotation/seed/arm 下汇合五折留出预测，得到 120 访问的完整六类混淆矩阵，再计算指标。总体平均三个业务组、八轮换和三个 seed 的 72 个指标值；不集成概率，不先平均折 F1。

CE 以 bit 计，对目标概率下限 1e−30；Brier 为六类概率与 one-hot 差的平方和，不再除以六。BA 为六类 recall 均值。new 的 CE/Brier 仅对目标业务访问计算；new F1 的 precision 仍来自完整六类。

bootstrap seed=20260928，10,000 次，每业务从五个内容有放回抽五个，保留每内容四重复。相同内容权重应用到所有方法、部署和轨道，且不重新拟合模型。对每次抽样重算混淆矩阵指标后，先平均同一对照的组/轮换/seed，再做 paired 减参照。

W 五部署×两项主比较为十项家族，区间取 0.0025/0.9975 分位；T 四部署×两项为八项家族，取 0.003125/0.996875。每部署两项调整后下界都大于零才通过。两家族分别控制，不声称合并十八项仍有同一个 5% 家族错误率保证。1 个百分点只是实际意义参照，不用于挽救未通过比较。

其他区间来自已保存数组，只报告普通 95%，不追加确认性地位。三个 seed 是训练随机性检查，不是三个独立内容样本。区间条件于冻结模型、样本及 C/U 选择，不覆盖重新采集、外部节点或完整训练重复的不确定性。

## 结论与限制

W/T 各自全部通过主判据，支持在登记设置下用有限真实配对产生有用额外训练摘要，并优于本轮内容级控制。不能推出任何组级方法都不足或所有精确配对机制都有效。

T 的 SS 上 marginal 高于 paired；W 的 Trojan center 点估计较高；这些负向例外均保留，不替换主方法。W/T 本身同时改变观测与参数化，不能从排名作单因素因果归因。reference 是更多目标侧资源的参照，不是理论上界，区间跨零不等于等效。

未验证：Hy2 分类、未见部署或配置、跨日期、外部 DIRECT 到代理、无索引在线分段、单 flow 分类、真实协议流量生成，以及减少标签需求。内容只有每业务五个，历史反复分析与回顾性选择风险不因部署数增加而消失。
