# DP-GAN1-M v1 full NER1 execution

The user authorized only a cumulative resource amendment: 40 hours activity,
32 hours conservative forecast. Model/loss/data/numeric gates remain unchanged.
Both stopped parent runs are immutable. This directory does not import their
runtime common modules or their full experiment launchers.

## Numerical policy

The seven numerical modules, including the accepted-point certified LBFGS,
are AST-identical to the sealed NER1 pilot. Convex heads have four independent
workers; dynamic jobs are grouped by capability, shape and one learning rate,
with up to 32 models, eight streams and CUDA Graph. The original 2,000/10,000
strict head budgets, 1e-5 original-gradient and 1e-10 replay gates are retained.

## Entry points

Use `D:/Tools/Anaconda/envs/Pytorch312/python.exe`.

1. `register.py` binds all 780 P0 packages and imports the accepted NER1 pilot
   heads/paths without refitting. The old and pilot cumulative ledger is carried.
2. `seal_code.py` freezes executable sources and the original numerical bindings.
3. `smoke.py controls`, then `smoke.py train-replay --cap P/G/E`, then
   `smoke.py seal` independently replay pilot imports and enforce negative
   query/label barriers. These stages do not add scientific candidates.
4. `driver.py` runs all inner model queues, seals all 21,600 inner endpoints,
   predicts all inner post queries, then selects PURE/FUSE policies. It fits the
   selected outer union, seals all outer endpoints, predicts all H, scores and
   independently verifies all results, and generates a complete result report.

The output root is
`outputs/deproxy-moment-game-v1-20261016/full-ner1-01`.
No implicit restart or continuation of an incomplete terminal is implemented.
Any failed original numerical gate, integrity failure, child failure or 40-hour
guard stops the schedule with pending work unmodified. A pending model never
becomes a beta-zero fallback.

## Data permissions

P/G/E workers run in separate OS processes. Workers consume only registered
role training assets; every historical and generated read is audited. G never
decodes P pairs. E never decodes pre/scales/pre or pre moments. Query features
require all appropriate models sealed; labels require all predictions sealed.
H inference uses only raw post96 and frozen exports. Initial/Adam/refit PURE
head comparisons are separately registered descriptive post-only outputs,
never an additional main-method selection rule.

## Costs and files

The coordinator reconciles complete child wall time with stage activity and
is the sole ledger writer. A wall-time watchdog terminates only its own child
at the remaining cumulative allowance. Training intermediates and failures
are retained. Physical reused/new counts are separate from logical endpoints.
Progress, active-child PID, stdout/stderr, capability read logs, budget and
source seals remain inspectable while the long run is active.
