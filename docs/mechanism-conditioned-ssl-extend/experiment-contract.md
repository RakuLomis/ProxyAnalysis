# Extend 机制条件化配对表示学习实验契约

日期：2026-10-04。用户已批准实施。当前注册的是五个已见部署的 E1，不自动开始 E2。本契约在正式训练和测试评分前保存，不代表已有收益。

## 数据与观测

沿用封存 Extend 队列：600访问、30内容、六业务、五部署、四次重复编号1至4。五折全局内容留出，每折480训练、120测试；同内容跨部署、全部重复、父访问两侧及内部连接整体同折。W为窗口正传输载荷字节，含重传；P为事件，R为窗口全局方向段，不是原stream FR。八个pre统计只用于预测条件，不输入正式post编码器。

## 固定方法

共享E为6→64→32 ReLU，P为32→32→16，条件矩阵A为零初始化的无偏置6→32；相对源表示增加A乘预测条件再作配对对比。条件使用P3的D1_pair、D2_pair、D2_group的decoded raw_center，与query pre的冻结phi之差经训练尺度处理。每个条件来自不含该内容的18内容中心，禁止真实query post进入条件。

协议机制仅为已审计经验先验，不是精确K或完整状态：当前Extend VLESS无REALITY/Vision，SS为aes-256-gcm，AnyTLS复用状态未完整观测。Hy2不因本计划获得分类资格。

## 臂与预算

B0同架构直接post监督1000步；B0L监督2000步并在中间重置Adam状态；B1普通post SSL；B2两侧侧内SSL；B3无条件真配；B4通用中心条件真配；B5机制中心条件真配；B6匿名内容组条件。

各SSL1000步，四个编码槽；共同post两遮盖视图，另两槽分别post/post、pre/pre或pre/post。每视图均匀遮一个标准化坐标；这是学习扰动不是合法流量变换。温度0.2，辅助权重1。负例仅同部署不同内容；同内容其它重复非负例。每批六内容、四重复、五部署共120访问；1000步每输入槽每访问250次曝光。

B6没有共同session/repetition，中心也是group拟合。组内4×4每正例单独分母损失平均，负例集合不变，两侧各四次编码一次，不把16组合当独立访问。B1四post槽，B2两post两pre，B3至B6三post一pre，不能写成各侧曝光全部相同。

同架构最终业务模型为3782参数，不能仅与旧422参数模型比较。冻结诊断包含R0随机及六SSL来源、线性和MLP各1000步，共210头；端到端真实post微调1000步，不用合成替换监督槽。最终120模型，SSL90模型。三seed为20260918/19/20。Adam lr0.001，weight L2=5e-5，bias不惩罚，无测试调参或早停。

## 权限 CUDA 与工程门

正式业务推理包只有test_post六量；协议、content、session等仅用于离线路由与评分，不是数值输入。SSL不读业务标签。诊断包读取test pre必须在业务预测封存之后，不能进入微调、尺度或选择。中心交叉拟合不等于新独立数据。

Pytorch312；回归与phi核验CUDA float64，编码器及分类训练/测试CUDA float32，无TF32/AMP或CPU回退。先检查参数、phi重放、损失手算、组内置换梯度、独立批处理和权限拒绝，再固定20步烟测。数值或哈希异常停止，不静默改预算。模型重载以不同推理batch回放，最大概率误差门限1e-5并要求决策一致。

## 统计和停止

主量为三seed的部署等权完整六类macro-F1；同时保留最差部署、每业务、每seed、CE bits、Brier与错误迁移。五项主比较为B5−B0/B0L/B1/B4/B6，共一个家族；B2/B3为解释性比较。10,000业务分层内容簇bootstrap，跨部署和seed同步，五项校正分位0.005/0.995。冻结探针和检索仅诊断，不用有利上游指标替代主终点。

保留旧P2/P3物理身份资格及五例未见SYN、历史预检曝光限制；软件权限不等于OS沙箱。结果来自反复研究的固定内容，不是外部盲测。完成后冻结，不自动搜索lambda、mask、扩大模型或启动E2。详尽设计在本地plan；机器契约、角色、输入/代码哈希及审计保存于新outputs目录，旧P3保持只读。
