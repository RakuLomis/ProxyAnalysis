# P0–P4 实验组完整总结：设计、配置、结果与结论边界

日期：2026-09-18。范围：已完成的 P0–P4、240 队列教师分法敏感性、299 保守队列敏感性。

本文是一份可独立阅读的汇总。正文给出研究问题、样本和实现口径、主要结果及解释；文末数值附录直接读取已落盘结果，列出全部模型臂、预设权重、教师分法的指标和关键收益区间。本次仅整理报告，不重新训练、不改变队列、不新增采集或推送仓库。

## 1. 总体结论

本组实验将“代理变换可观察”“真实对应具有分析价值”“这种价值改善单侧业务学习”拆成不同问题，得到以下结论：

1. **测量层有清晰模式。** 0916 的 SS 表现为载荷字节相对接近原值，而包数、包含空载荷包的方向段显著增多；VLESS 的非空方向段 FR 增加更一致。变化同时具有业务依赖，不是全协议无条件定律。
2. **双侧业务预测结构存在。** 部分任务中 Joint 或 Pre 的业务预测损失明显低于 Post；但它们在测试时使用 pre，不能计作单侧业务效果，也不是理论上界。
3. **未发现软监督目标的实现尺度错误。** 关闭教师项、one-hot 教师、权重守恒和显式损失/梯度核验通过，历史基线可以复现。
4. **教师较好不等于学生获益。** 实际 pre OOF 教师整体优于 post OOF 教师，但六类同部署学生仍未稳定超过硬标签 M0。
5. **联合教师没有普遍解决这一问题。** 真/错配联合教师的差异较小或对教师分法敏感；条件一致性的理论理由不能替代有限样本结果。
6. **跨部署存在局部改善，但不能写成普适收益。** SS→VLESS 与反向不同；有些损失改善优于错配，却不如普通 post 教师，有些甚至不如错配。F1 与 CE 也不总同向。
7. **表示改进不保证迁移改进。** distribution157 能提高部分同部署 F1，却可能产生更大的跨部署损失。

最稳妥的总判断是：当前数据支持部署相关变换和有条件的配对依赖，但尚未支持稳定、普适、精确配对专属的单侧业务净收益。负向结果是利用边界的证据，不是所有配对学习方法无效的证明。

## 3. 数据、业务标签与分析单位

### 3.1 原始数据与实际使用范围

0916 原始批次包含七业务、35 个登记内容、SS/VLESS/Hy2 三部署、五轮，共 525 次选定访问；538 个保存尝试中有 13 个先前尝试，不作为额外重复。TrafficTracer 1.0.27、cold 模式、配置采集 60 秒。

本组业务模型只用六业务、30 内容、SS/VLESS 的严格排他 TCP 配对部分：

| 队列 | 数量 | 用途 |
|---|---:|---|
| 已提取候选表 | 300 | 两侧特征全集，不等于全部批准训练 |
| 主队列 | 240 | 第 1/2/4/5 轮；P0–P3 主实验和 P4 主统计 |
| 保守队列 | 299 | 加回有效第三轮，仍排除唯一 MDN 恢复访问 |
| 0914 历史严格队列 | 140 | 仅 P4 描述性参考，不进入业务训练 |

240 与 299 来自同一批数据，不是两个独立数据集，不能相加作为样本量。YouTube 二类任务是六类数据的子集。

### 3.2 六个标签

业务标签为 domain × activity：

- `bing.com::search_results_view`
- `developer.mozilla.org::document_view`
- `github.com::repository_view`
- `wikipedia.org::article_view`
- `youtube.com::search_results_view`
- `youtube.com::video_playback`

每类五个登记资源。多数 domain 只有一种 activity，六类任务可能大量利用站点模板；YouTube 二类任务更直接控制顶层 domain。不同资源不等于主题独立，文档/文章 page_load 也不证明真实阅读行为。

### 3.3 排除与降级口径

有正片播放即可接受视频标签，不要求一定达到配置的 25 秒目标；degraded 不等于无效。Bilibili 已接受目标级人工播放确认，但主目标 DIRECT，故不进入严格代理业务主队列。Hy2 的共享 UDP carrier 和路由策略差异不适用当前排他 TCP 实验。

MDN Overview、SS、第 3 轮超时恢复访问最终 HTTP 200 且 URL 正确，不被宣称为确定失败，但按保守决定暂不纳入 299。没有因模型表现负向放宽至 300。

### 3.4 样本单位与来源核验

模型每次访问一行，由原始实体内计算的包特征汇总而来，不将同一 flow 的切片随机拆到不同集合。300 候选包含 3,246 个排他 TCP 配对、6,492 个两侧捕获记录；它们不是独立内容样本。

此前身份门在该范围未发现跨会话相同捕获路径/哈希；222 组 TCP 元组复用比较未发现时间重叠、相同时间戳与原始字节包交集或相同初始 SYN 身份。本组实验继续核验冻结输入。其结论不外推到整个原始数据集或所有潜在混杂。

## 4. 特征与观测定义

### 4.1 scalar14

| 字段 | 含义 |
|---|---|
| packet_count | observed 包数，含空载荷包 |
| transport_bytes | 传输载荷字节总和 |
| ip_bytes | IP 总长度之和，不是 IP 地址 |
| up_transport_bytes / down_transport_bytes | 两方向传输载荷字节 |
| burst_count | 含空载荷包的同方向连续段数，各实体求和 |
| fr_runs | 非空 TCP 方向段数，首段计 1，各实体求和 |
| fr_switches | 非空方向切换数，首段不计切换 |
| fr_runs_per_packet | FR 段数 / 非空包数 |
| up_byte_fraction | 正方向载荷字节占比 |
| transition_p_pm | 非空序列中正方向转向反方向的条件概率 |
| direction_entropy | 非空包方向比例的二元 Shannon 熵 |
| length_median | 非空传输载荷长度中位数 |
| iat_median_us | 实体内相邻 observed 包 IAT 的合并中位数 |

FR、burst、IAT 与转移不跨不相关实体边界构造。FR 与 burst 包筛选不同，不应混称；direction_entropy 也不是业务互信息。

### 4.2 distribution157

\[
157=14+19\text{（长度概率桶）}+23\text{（IAT 概率桶）}+101\text{（累计曲线）}.
\]

固定边界包含上下尾桶，每侧、每直方图独立归一化。累计曲线按单侧时间和载荷归一化。空直方图作为缺失块，仅由训练侧填补，不假造均匀分布。Joint 为 28 或 314 维。

### 4.3 两种“变换”不可混用

P1 的业务诊断表示：10 个非负尺度标量取 `log1p(post)−log1p(pre)`，4 个比例/概率/熵取差；分布版再追加逐桶和曲线差。

P4 的尺度测量：严格 `ln(post/pre)`，不加 1，零值应单列。P4 的 JS 是 base-2 散度，不是距离平方根。

### 4.4 不进入模型的信息及观测边界

IP 地址、MAC、端口、SNI、domain、路径、session_id、绝对时间、captured_bytes 派生量不进入 X；它们可用于配对、标签、分组及审核。计算使用项目算法，不依赖 Wireshark 内置统计结果。

测试学生只接收 post 数值矩阵，但访问的连接范围由离线索引辅助界定。因此口径为 `offline_index_assisted_post`，不是未知混合原始流量上的在线分割闭环。

## 6. 评价指标与统计口径

主要指标是 CE(bits)，次要指标为 macro-F1、balanced accuracy、Brier、混淆矩阵。Brier 为多类概率误差平方和的均值，不除以类别数。

\[
G_{task}=CE(M0)-CE(真实学生),\quad
G_{pair}=CE(错配学生)-CE(真实学生),\quad
G_{soft}=CE(M1)-CE(真实学生).
\]

M2 的错配对照为 M3，J-True 的错配对照为 J-Wrong。正值均代表真实学生损失较低。G_pair>0 不保证 G_task>0；G_task>0 也不能单独证明收益来自精确对应。

240 各内容重复数相同，访问等权等价于内容等权。299 指标每内容总权重相等。收益区间先在内容内平均重复差，再按类别内内容重采样 2,000 次；条件于已拟合模型，不重训练，不代表外部环境不确定性，也没有多比较同时置信保证。

CE 使用 1e-12 概率下限，单次损失约封顶 39.86 bits。F1 提高而 CE 变差、或 CE 改善而 F1 很低均需并列报告，不能事后换主指标。

## 7. P0 最终结果：没有发现目标实现错误，但教师质量不足以解释收益

真实数据四个任务/部署首折通过直接硬标签 LR、α=0、one-hot 教师、历史 M0 复现及模型参数重建检查，概率容差为 1e-10。合成二类/六类测试通过权重守恒、显式软损失和梯度等价。

实际 scheme=0 OOF 教师的上下文平均 CE：六类 SS 的 pre/post 为 0.4524/0.6884，六类 VLESS 为 0.7132/1.1229；YouTube SS 为 0.3903/0.5894，VLESS 为 0.8890/1.1360。pre 较好，但这没有自动带来学生净收益。

教师每类只见两个内容，完整 pre 诊断模型每类见四个内容，不能替换使用。教师训练侧内层 OOF 与学生外层测试 OOF 不属于同一个样本训练事件；诊断按模型上下文呈现，不把相同访问在不同上下文出现的记录当作独立样本或因果配对。

## 8. P1 最终结果：双侧诊断有价值，强表示并非一致改善

scalar14 六类 SS 的 Post/Pre/Joint CE 为 0.5797/0.3602/0.3396，VLESS 为 0.9310/0.5910/0.5553。Joint 的较低损失支持当前有限学习器能够利用双侧业务结构，但增加输入也改变容量和正则化几何，不是条件互信息的直接估计。

distribution157 的六类 VLESS Post F1 从 0.7713 增至 0.9414、CE 从 0.9310 降至 0.4142；但 YouTube VLESS Post F1 虽增至 0.9250，CE 却从 1.0680 升至 1.4121。表示升级的作用不是一致的。

Joint 不总优于 Pre，Transformation 不总优于 Post，也不能将变换含业务预测结构解读为纯语义/纯协议因素已经分离。

## 9. P2 最终结果：联合教师未解决六类同部署净收益

在 scalar14、α=.5 下：

| 任务、部署 | M0 CE | M2 CE | J-True CE | J-Wrong CE |
|---|---:|---:|---:|---:|
| 六类 SS | 0.5797 | 0.6429 | 0.6265 | 0.6248 |
| 六类 VLESS | 0.9310 | 0.9996 | 0.9956 | 0.9830 |

## 10. P3 最终结果：迁移方向和一般软监督对照决定解释

对外层折 k，源训练只含非 k 内容，目标测试只含 k 内容，源的 k 内容也未用于任何训练。目标部署其余内容不作为预处理、适配或校准资源。每个学生的源测试与目标测试共用 fit_id。

### 10.2 分布表示揭示迁移脆弱性

distribution157 六类 VLESS→SS 的 M0 CE=6.3267、M2=4.2271，比值表示升级前的绝对损失更差；M2 对自身表示基线有局部收益，不等于胜过更简单的 scalar14。

YouTube SS→VLESS 的 distribution157 M0/M2 CE 为 9.8781/4.0229，看起来改善很大，但二者 F1 都为 0.3333。它更多反映错误概率置信程度变化，不能称为良好业务识别。

完整结果包含所有方向、臂和 α，不合并方向掩盖差异。该实验仍是固定批次内跨代理部署验证，不是纯协议因果效应或跨环境盲测。

## 11. 敏感性最终结果：局部正向结论进一步收紧

240 增加 scheme=1、2，299 运行 scheme=0，均固定 scalar14、α=.5、六个臂。没有根据首轮赢家筛掉其他方法。

### 11.1 六类同部署结果一致

240 三分法中，SS 的 M2 G_task 在 −0.0632 至 −0.0561、J-True 在 −0.0469 至 −0.0365；VLESS 的 M2 在 −0.0931 至 −0.0671、J-True 在 −0.1035 至 −0.0545。299 同样为负。

### 11.2 六类 SS→VLESS 的配对优势弱于主分法所显示

## 13. 信息论解释与研究边界

固定教师、同一总体分布、无限制学生类且不考虑正则/有限样本误差时，混合交叉熵最优学生为：

\[
q_\alpha^*(y|B)=(1-\alpha)p(y|B)+\alpha E[q_T(y)|B].
\]

理想联合教师满足 E[p(y|A,B)|B]=p(y|B)，但理想 post 教师也满足一致性；理想硬标签总体学习本已达到 p(y|B)，联合教师不能突破 B 的 Bayes 极限。

因此理论提供设计理由，而不是实际收益保证。pre 教师准确不必意味着其条件平均监督适合 post；联合教师也存在估计误差和跨部署分布变化。本组结果不能被称为测得真实互信息、证明变换可逆或语义解耦。

剩余限制包括：同批次/固定节点、按业务成块采集、协议与节点/时段混杂、每类仅五内容、同站点模板、YouTube二类仅十内容、离线索引辅助页面范围、回顾性研究选择、条件于模型的区间以及多指标比较。模型输入不含 IP/SNI 不能排除这些通过长度/时序体现的环境线索。
